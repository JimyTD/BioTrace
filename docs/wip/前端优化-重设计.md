## 0. 这句话先钉死

产品已经有主路径（旅途 → 相册上传 → 开包高潮 → 图鉴/套册），缺的不是新功能堆砌，是**整站还不像同一本旅行相册**。

- **开包**已接近高潮完成度（纸、框、火漆）。  
- **旅途列表 / 相册格 /「我的」信息架构**刚开了头，仍粗糙。  
- **登录、地图、图鉴、观察详情、相册管理/共享**基本还是通用表单 + 圆角卡片。

翻新范围：**交互逻辑、排版层级、主题色调、美术资源**。不改识图/稀有度结算核心。

### 0.1 三层：大体不动，图可换

从第一刀就要按这个拆，不要「先出一张很好看的图再倒逼布局」。

```text
1. 骨架     这一屏有什么、谁主谁次、点哪里进二级     ← 大体
2. Token    色 / 字 / 圆角 / 阴影                       ← 换皮
3. 槽位资源  约定文件名、比例、是否透明、内窗 inset      ← 可替换
```

| 层 | 改它等于 | 不该发生的事 |
|----|----------|----------------|
| 骨架 | 改产品怎么用 | 为换一张底图复制页面、改路由、改开包流程 |
| Token | 整站换气质 | 只在某一页写死 hex |
| 槽位 | 换一张 PNG/SVG | 组件写死 `/trips/daylight/foo.png`；图自带相框/文字；半透明边垫当框 |

**槽位要先写契约再出图。** 例如「底栏」契约可以是：高度固定、四项、激活态用 token；若以后要纸纹，只加 `nav-texture.png` 铺在栏内，栏的结构和点击区域不变。封面框契约已经是：几何 SVG、中心挖空、边垫不透明、照片在 6% 内窗。换一张 `cover-frame.svg` 不应改 `TripsPage` 逻辑。

Cut A 问「底栏要不要邮戳感」本质是：**骨架先做成标准底栏**；邮戳/纸纹是可选槽位，没有图时 token 底也能用。先花活再骨架，图一换整页就塌。

出图纪律仍见 §5；helper 只经 `themes/*Assets.ts`。

## 1. 已验证的原则（本线必须遵守）

从开包、旅途、我的三轮实战里收来的，不要再踩：

| # | 原则 | 反面教材 |
|---|------|----------|
| P1 | **主屏变薄。** 日常路径留在第一屏；改密、高级配置、运维状态进二级 | 「我的」曾把 UUID、Gemini 状态、改密表单全摊开 |
| P2 | **照片优先，框是几何 SVG。** 边垫必须不透明；照片放进 overflow 内窗再缩放 | 半透明框 + hover scale → 穿模 |
| P3 | **空态用文案，不要整幅「摆拍风景」**；**页面底必须是纸，不是纯色 hex** | 旅途空态插画带字、难溶进页面；反过来把整本相册铺成电脑灰底 |
| P4 | **本地静态预览要像真机结构**（顶栏 + 内容 + 底栏），再用用户照片样片，不用抽象占位 | 绿椭圆「测框图」进预览 |
| P5 | **文案直白。** 按钮写「创建」不写「开册」；lede 给人看，不写「环境状态」 | — |
| P6 | 表现三分离：文案 `packages/messages` · token `themes/*.css` · 结构 `styles.css` + `pages/` | 禁止页内写死 hex / `/volumes/daylight/` |
| P7 | 换皮只换 token + `public/<pack>/<theme>/`，**不复制页面** | 不为换皮分叉业务流程 |
| P8 | 满意再推；真机 WebView 不信 CSS mask | 火漆方底、框线错位 |
| P9 | **先骨架与槽位契约，后出图。** 美术可换，不能倒逼布局 | 空态风景图风格不统一、带字、难替换 |

气质锚点（日光胶片）：**暖纸底、柏褐字、陶橙 CTA、铜版/齿孔几何、开包才用火漆高潮。** 不是 scrapbook 摆拍，不是紫霓虹抽卡，不是冷绿 SaaS。

## 3. 交互逻辑：要改的不是「加功能」

### 3.1 全站共性

- **第一屏只回答一件事。** 旅途=封面墙；相册=看图+加入；图鉴=册与种；地图=点；我的=这是谁。  
- **设置与管理用二级页或明确「管理」开关**，不要默认展开表单。相册「管理旅途」已进 `/trips/:id/manage`。  
- **主按钮每屏最多一个**（加入照片 / 请过目 / 创建）。其余 `secondary` 或行+箭头。  
- **错误与空态说人话**，技术细节（UTC、error code、用户 ID）放二级或日志。  
- **共享旅途**控件（邀请码、成员、踢人）是管理员路径，默认藏进「管理」。

### 3.2 分表面要点

| 表面 | 交互方向 |
|------|----------|
| 登录 | 默认只露登录；注册/重置是切卡，不是三个表单叠在一起抢视线 |
| 旅途列表 | 保持内联创建但视觉降权；共享旅途用角标，不在封面下堆三行 meta |
| 相册 | 默认：头（返回/标题/摘要）+ 加入 + 胶片格。上传器点开才展开。管理/共享进二级或底部抽屉，勿与格子抢第一屏 |
| 开包 | 维持封缄→揭示→展出；勿把套册仪式塞进开包主路径 |
| 图鉴 | 第一屏套册架；点开整页内页；已收录是可搜索目录 |
| 地图 | 底图铺满主区；选中用底部信息条（图+名+进详情），旅途文字链；不在地图上弹卡 |
| 详情 | 上大图；名字/稀有度徽章/简介/分类/记录展开；危险操作沉底 |
| 我的 | 已按此做。后续只补皮肤入口，勿把表单搬回主屏 |

## 4. 排版与主题色调

### 4.1 结构统一（`styles.css`）

所有 Tab 用同一套页头：`.page-head` + `.page-title` + 可选 `.lede`。禁止再混用登录页 `.brand` 当内页标题。

抽可复用件（不要每个页一套）：

- `.me-menu` / `.me-row` → 升为通用 **设置行**（账号安全、图鉴筛选项等）  
- `.me-identity` → 通用 **名片/扉页条**  
- `.me-section` → 通用 **二级页卡片**  
- 胶片格 / 封面窗：已有 `.film-tile-window`、`.trip-cover-window`，图鉴与详情 hero 向它对齐

内联 `style={{ gap: "0.35rem" }}` 收进 `.field` / `.me-field`。

### 4.2 Token（`daylight.css`）

先把 daylight **用全、用对**，再谈第二套皮肤：

- 清理 `styles.css` 残留硬编码 hex（如部分 backdrop）  
- 补齐「设置行 / 名片 / 二级卡片」语义 token，与 `--trip-*`、`--volume-*` 并列  
- 底栏、顶栏与页面氛围同一纸色家族，避免一块灰一块米  
- 稀有度色阶已定（灰→蓝→紫→金→红→彩虹→洋红），徽章与火漆继续共用，不要图鉴再发明一套

`tide`：冷灰青纸、深潮池字、海璃 CTA；仍是纸质相册，不是霓虹潜水电脑。稀有度色阶与 daylight 共用。整包插画后补。

### 4.3 动效

克制：内窗内轻 scale、开包壳抬起、空态淡入。禁止封面整体抬升导致穿底栏。新动效先在静态预览里看，再进 React。

### 6.9 Cut I · 动效与真机债（施工中）

- `viewport-fit=cover`，顶栏/底栏/登录/弹层吃 `safe-area-inset`（含左右刘海）。
- `html/body` 锁 `100dvh` + 禁 overscroll，避免 WebView 回弹把内容从底栏底下拽出来。
- 封面照片放大只在真正有 hover 的设备上；触摸不再粘住 scale。
- 开包壳抬起保留；`prefers-reduced-motion` 时关掉。
- 邮票格 `overflow: hidden`，防相框穿模。

**不改：** 识图/稀有度、地图引擎、开包叠层 inset。

### 6.10 Cut J · `tide`（施工中）

- 日常页用 `--bg-atmosphere`（颜色和光），不整页贴纸的照片。

- 静态预览：`public/themes/preview.html`。

**不改：** 识图/稀有度公式、地图引擎、开包叠层 inset、业务流程分叉。
