# 创作方案（临时）

> **性质：施工计划，不是功能真源。** 功能仍以 [`SPEC.md`](../SPEC.md) 为准。  
> 上一线「收纳」见 [`前端优化-重设计.md`](./前端优化-重设计.md)，已推完 A–J。本文件只服务下一线：**创作**。  
> 创建：2026-08-13

## 0. 这一线要解决什么

收纳已经做完：该藏的藏了，别扭的摆正了，布局能用。  
创作要解决的是：打开 App 时，人觉得自己在**翻一本带着走的旅行相册**，而不是在用一套整理过的功能页。

不是再换皮，也不是全站特效。是选一个想象，让旅途、相册、开包、图鉴、地图都为它服务。

用户给的「海浪冲出贝壳」是胆量标尺，**不是**本线题材。本产品的物件已经有了：封面旅途、胶片格、开包火漆、套册邮票。创作落在这些上。

## 1. 一句通线（先钉死）

**打开旅途 = 翻开一本；相册里的照片 = 卡进齿孔的相片；开包 = 唯一一次揭开。**

- 日常：克制。翻开、入槽、走动。  
- 高潮：仍然只有开包。创作线**加厚开包前后的期待**，不另造第二高潮。  
- 地图：这本相册里夹着的折页，不是 GIS 工具。  
- 图鉴：同一本家里的分册，可以翻开细看。

文案仍然直白（「创建」「加入照片」），不把按钮写成「开册」「入槽」。想象在动作里，不在术语里。

## 3. 三个方向（只选一条做满）

### A · 翻开一本（推荐）

整 App 是一本带着走的相册。

| 表面 | 创作后应感觉像 |
|------|----------------|
| 旅途列表 | 一排合上的封面。点下去是**揭开/翻开**，不是切路由淡入 |
| 相册 | 齿孔格是这本的内页。新照片是**推进槽里**，不是在网格里 pop |
| 开包 | 已有高潮。前面加「待开的封」在相册里也看得到厚度 |
| 图鉴 | 从这本里抽出的分册；内页翻一张邮票像掀一页铜版 |
| 地图 | 夹在封底的折页摊开；选中 = 抽出一张现场照 |
| 登录 | 合上的封面；登录是掀开扉页 |

胆量：进旅途这一下必须够大，大到你觉得「终于不像后台了」。其它屏跟住这一个动作，不另发明。

### B · 冲洗与入槽

主隐喻是暗房/入槽，列表仍是封面墙。进相册像揭开保护纸，照片从灰到清（短、克制）。开包仍然是唯一长高潮。  
风险：和开包抢戏；暗房黑底与日光胶片冲突。只作 A 的局部手法，不独立成线。

### C · 集邮细看

主隐喻给图鉴：邮票可拿起、可侧光、可翻面看记录。旅途/相册仍偏收纳。  
风险：图鉴亮、主路径（旅途）仍平。创作应从人每天进的门开始，不从图鉴开始。

**本线选 A。** B 的「入槽 / 短揭开」并进相册；C 的「拿起细看」并进套册内页。

## 4. 创作纪律（收纳原则仍然有效）

上一线 P1–P9 不作废。创作额外加：

| # | 必须 | 禁止 |
|---|------|------|
| C1 | **一个通线做满**，其它屏跟动作，不跟装饰 | 每屏一个新比喻（沙滩+胶片+邮票+海浪） |
| C2 | 高潮仍只有开包 | 列表、底栏、登录再贴火漆/邮戳 |
| C3 | 动效是**物件在动**（掀盖、入槽、抽出） | 全屏粒子、海浪、模糊转场当「设计」 |
| C4 | 照片仍是主角；框仍是几何 SVG | 不规则 PNG 相框、胶带、贴纸 |
| C5 | `prefers-reduced-motion` 时动作收成切页 | 创作 = 强迫看动画 |
| C6 | 真机 WebView 先预览再推 | CSS mask、重 3D 翻书、shader 主路径 |
| C7 | 不为创作改识图/稀有度/开包 inset | 「为了更像暗房」去改结算 |

日常仍然克制：没有照片时，空态是空齿孔 + 一句话，不上风景插画。

## 5. 施工顺序（一次一块表面）

每块：**先做静态预览里的「进/出」动作 → 真机 → 再下一块。** 不为了先看见大特效去抢开包。

| 序 | 块 | 怎样算创作到位 | 依赖 |
|----|----|----------------|------|
| K | **进旅途** | 点封面 → 有翻开/揭开；回来像合上。路由可以仍是 `/trips/:id` | 收纳已完成 |
| L | **相册入槽** | 格子先在；新图是推进窗里。待开包的格有封、不是灰字 | K |
| M | **套册内页** | 点邮票像拿起；完成章仍是角上火漆，不抢开包 | L 后更顺 |
| N | **地图折页** | 进地图像摊开夹页；选中条像抽出一张。审图号仍在右下 | K |
| O | **登录扉页** | 未登录是合上的封面 + 一句 lede；登录后掀开到旅途 | K 的同一套掀法 |

刻意后置：全站 3D 翻书、放大镜 shader、打印实体书、自动轨迹、朋友圈。

## 6. 第一刀建议（Cut K）

只做一件事：**点旅途封面，像翻开一本。**

```text
列表：封面墙（已有）
点封面 → 封面抬起/掀开（短）→ 进入相册内页
返回 → 合上，回到墙
```

- 不改上传、管理、共享逻辑。  
- 动效可打断、可减动。  
- 静态预览必须是真机结构（顶栏 + 内容 + 底栏）。  
- 列表本身先不要撒一地倾斜拍立得。

这一刀够大，后面 L–O 都长在这个动作上。不够大，创作线会再次变成「微调转场」。

## 8. 技术怎么做（不改业务语义）

现状：`TripsPage` 用 `<Link to={/trips/:id}>`，`App` 里列表和相册是**平级路由**。一点封面，列表卸掉、相册挂上，壳（顶栏/底栏）不动。没有转场库，开包已经是 **CSS keyframes + 相位 class**（`SettlePackStage`）。Android 是 Capacitor WebView。

### 8.1 不选什么

| 方案 | 为什么不用 |
|------|------------|
| turn.js / StPageFlip / 全页 3D 翻书 | 廉价拟物；WebView 卡；和几何框纪律冲突 |
| Framer Motion / 新动画库 | 开包已经证明 CSS 够用；少依赖 |
| View Transitions API 当主路径 | 共享元素是**快照拉伸**，封面 3:2 → 相册整页会拉成「照片放大」，不像翻开。Firefox / 旧 WebView 还要降级 |
| 卸掉列表再 FLIP 回去 | 返回时封面墙还不在 DOM，对不上位置，合上会抖 |

View Transitions 以后可给「图鉴 → 详情」这种真·共享元素用，不当 Cut K 主路径。

### 8.2 主路径：封面墙常驻 + 相册当「打开的一本」

路由仍是 `/` 与 `/trips/:id`（管理页 `/trips/:id/manage` 仍独立，不嵌进书里）。

改的是挂载：

```text
main
  ├─ 封面墙（TripsPage 在 / 和 /trips/:id 都在）
  └─ 打开时：相册层盖住 main 的可视区（顶栏/底栏仍是壳）
```

- 墙还在：滚动位置在；返回能对上那一本封面。  
- 深链（地图/开包回相册、刷新 `/trips/:id`）：没有起点矩形 → **不演掀开**，相册层直接在。  
- 底栏「旅途」本来就指向 `/`，等于合上。  
- 墙在打开时 `inert` + `aria-hidden`，不抢焦点。

手递（只活在一次导航里，不入库）：

```text
{ tripId, sourceRect, coverUrl }
```

点封面时量 `getBoundingClientRect()`，再 `navigate`。没有手递就跳过动画。

### 8.3 Cut K 动作（两段，可打断）

**不要**把整本相册拿去 scale（3:2 → 整页会变形）。演的是**封面这张物件**，相册在它后面出现。

```text
1. 抬   克隆封面进壳内 portal（不被 .content overflow 裁掉）
         略上移、阴影加大          ~120ms
2. 开   克隆扩到内容区宽度；相册层 opacity 0→1
         克隆淡出                   ~280ms
3. 定   去掉克隆，只留相册层
返回    倒放：相册淡出，克隆缩回墙上那一本
```

第一版用 **transform + opacity**（和开包同一套）。`rotateY` 合页只当第二拍：第一拍看起来像「拿起一本」就够；若像「照片放大」再加 8–18° 浅转，**不要** 180° 翻面。

动态起止用 **Web Animations API**（`element.animate()`，可 `reverse()` / `finish()`）。写死 keyframes 对不上每本封面的屏幕位置。减动：`prefers-reduced-motion` 或系统减动 → 直接切层，和现在一样。

真机禁区（P8 已踩过）：大面积 `filter: blur`、`backdrop-filter`、CSS mask 当主路径。阴影用已有 `--trip-cover-shadow*`。

### 8.4 代码落点（Cut K）

| 新/改 | 做什么 |
|--------|--------|
| `OpenBookHandoff`（小模块/context） | 一次导航的 rect + 图；用完即清 |
| `TripBookLayer` | 盖在墙上的相册层；管抬/开/合 |
| `App.tsx` | `/` 与 `/trips/:id` 同挂封面墙；有 `:id` 再挂层。**不改** manage / settle / 识图 |
| `TripsPage` | 点封面先写 handoff 再 navigate；打开时墙 inert |
| `styles.css` | `.trip-book-layer` 绝对铺满 content 行；动效 token 可进 theme，结构 class 仍在这里 |
| 静态预览 | `public/trips/open-book-preview.html`（假封面墙 + 假相册，真机壳） |

不加 npm 包。相册页内部（上传、格子、删除）原样。

### 8.5 后面几刀怎么长在这套上

| 块 | 技术 |
|----|------|
| L 入槽 | 格子本来就在。只对**新出现的** `observation.id` 做短 `translateY` + 窗内 clip（对比上次列表，不要每次进页全格动画）。待开包：现有 veil 加厚成「封」，不是第二枚火漆 |
| M 拿起 | 同一套 portal：邮票 `sourceRect` → 检视层 scale 上来。无 shader |
| N 折页 | 地图已铺满；选中条 `map-sheet` 自下插入像抽出一张。从相册进地图没有封面矩形，不要硬演掀书 |
| O 扉页 | `App` 在 `user` 空/有之间整树切换，比 K 难。登录后再挂壳，用 K 的掀法短接。后置 |

### 8.6 验收（真机）

- 点封面：一本被拿起再打开；不是整页淡入。  
- 返回：缩回同一本；列表滚动还在。  
- 动画中点返回：能打断，不卡在半开。  
- 减动、深链、从开包回来：没有残影克隆。  
- 顶栏/底栏全程在；管理页仍是普通二级，不演翻书。
