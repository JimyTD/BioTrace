## 否决

全库预印灰格、只亮自己拍到的那一格。对猫狗也不行，更不许给马（或任何物种）单独开例外。禁止用 JSON 里的 `listed` 把对照表分成「能上卡 / 只能纠偏」。

## 当前权宜（代码现状，不是最终设计）

卡上只显示已点亮的标准格 / 自由格，以及点亮了的「品种不详」。所有物种同一条路径。
