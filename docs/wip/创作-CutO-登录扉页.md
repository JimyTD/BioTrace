# Cut O · 登录扉页

> **性质：施工备注，不是功能真源。** 通线见 [`创作-方案.md`](./创作-方案.md)。  
> 示意：[`apps/web/public/trips/flyleaf-preview.html`](../../apps/web/public/trips/flyleaf-preview.html)  
> **已接到正式页**（`LoginPage` + `App`）。

## 故事

| 你在哪 | 物件 | 动作 |
|--------|------|------|
| 还没进去 | 书名页 / 扉页（一整面纸） | 登录后这一页从书脊翻过去 |
| 旅途墙 | 一本本合上的相册 | 点封面 = 翻开那一本（Cut K） |
| 相册里的一张 | 待开的封 / 开包 | 揭开（唯一高潮） |

三层不要混。扉页不是墙上那本 3:2 封面，也不是开包。

## 合着时

整屏书名页：天头留白，题名居中，下面一根细线，表单落在地脚当版权栏。像不像扉页看版心，不靠再铺一张图。纸仍是 App 同一张（`--bg-atmosphere`）。

## 打开时

这一页从**左边书脊** `rotateY` 翻过去，字在封面上跟着走。不是从中间撕开，不是左右对开。动作用 `tween` + rAF（`motion.ts`），减动则直接进墙。

## 正式怎么挂

- 已登录刷新：不挂扉页，不演翻页。
- 登录成功：先 `setUser` 让 `AppShell` 挂在后面，扉页再翻过，然后卸掉。
- 登出：直接回扉页，不必倒放。
- 翻页时表单不接点击；字不要先淡出再翻空纸。
- 页背用 `--trip-cover-plate`，不要在 `pages/` 写 hex。

## 不改

识图、稀有度、开包、注册/重置接口。不为扉页给安卓做弱一档。
