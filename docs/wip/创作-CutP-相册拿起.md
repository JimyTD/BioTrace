# Cut P · 相册拿起（已接到正式页）

> **性质：施工备注。** 通线见 [`创作-方案.md`](./创作-方案.md)。

相册点一张：相片从齿孔窗里走出来，变成观察页大图。框不动。回来落回格子。深链、地图点进来：不演。减动时直接到位。

待开包（badge「鉴定完成」）**不飞照片**：飞的是相册里那只封缄格本身（模糊照片 + 腰封），放大落到开包页的信封上再化掉（`playSealLift`）。清晰的一帧会提前泄底，也不该穿进封着的信封。相册在下层仍挂着才取得到那只格子；取不到就不演。
