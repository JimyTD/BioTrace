# Cut P · 相册拿起（已接到正式页）

> **性质：施工备注。** 通线见 [`创作-方案.md`](./创作-方案.md)。

相册点一张：相片从齿孔窗里走出来，变成观察页大图。框不动。回来落回格子。深链、地图点进来：不演。减动时直接到位。

待开包（badge「鉴定完成」）**这一下不演**：点了直接到开包页，牛皮纸封已经在，和深链、地图点进来完全一致。相册那格根本不发手递（`liftable()`）。

别再给它接飞片：两端的主体都含照片——相册格是模糊照片横一条腰封，`pack-sealed.png` 是挖了窗的纸封、窗里透出的还是那张模糊照片。任何形变都等于让照片先飞一趟，提前泄底。揭封是唯一的那一下，进场不跟它抢。

回到相册要重取一次——开包页和观察页都可能改过状态（待开包 → 已收录、删除），而相册挂在覆盖层下面从不卸载，不重取格子就一直停在旧状态。但**重取必须等飞片落地**：飞行中换数据会让格子闪一下，也就是 `cffa57e` 修过的那个闪。代码里用 `refreshAfterLift` 挂账，落地回调里再补那一次。两侧都别单独改。
