v4 戏码清单：拿起（卡片上抬）→ 显影（深灰糊 → 冲清晰）→ 定色（档色成色 + 光柱从照片底边升起 + 白闪一拍 + 心搏白光 + 光尘上浮 + 星闪绽开 + 流光描边点亮 + LR/XR 虹彩扫光一道）→ 落章（药丸从高处砸下回弹 + 卡片随档位震颤）。
