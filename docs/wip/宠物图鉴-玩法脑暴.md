# 宠物图鉴 · 驯化名录与叙事

> WIP，非拍板；方案获准前不动代码。
> 更新日期：2026-09-29

---

## 1. 方向

- 范围是**驯化种**（含家畜），不是用户自家的某只宠物。
- 玩法长在**分类学**上，不扩展成个体档案、街猫志或宠物地图。
- 现状是「照片墙 + 次数」，与驯化种天然封闭、可数的集合不匹配。当前方向是改成**驯化名录 + 驯化叙事**。

---

## 2. 驯化名录

### 2.1 边界口径

| 口径 | 范围 | 问题 |
|---|---|---|
| A 学界驯化种 | 约 40 种，含骆驼、驯鹿、水牛、鸬鹚、蚕、蜂等 | 半驯养、水产养殖、实验动物是否计入存在争议，且多数用户拍不到 |
| **B 日常能遇见 + 家养型明确** | 十几到二十几种 | 边界按能否拍到确定，不交给学界裁定 |
| C 只要伴侣动物 | 猫、狗、兔、鸟、鱼 | 与「所有家养、驯化种」的范围矛盾，排除 |

推荐 B。B 是产品策展名录，不是客观全集；界面不能写「这是全部驯化动物」，只能说「我们这份名录」。避开水产养殖、实验动物、半驯养三个争议区。

### 2.2 分栏

按「人怎么对待它」分栏，不从分类树、起源地或年代切：

| 段 | 人怎么对待 | 例 |
|---|---|---|
| **同住** | 进家、同桌睡 | 家犬 · 家猫 · 家兔 · 豚鼠 · 仓鼠 · 金鱼 · 锦鲤 · 虎皮鹦鹉 · 玄凤 · 红耳龟 |
| **畜养** | 圈着取用 | 家猪 · 家牛 · 家鸡 · 家鸭 · 家鹅 · 家鸽 · 火鸡 · 鹌鹑 |
| **使役** | 养着干活 | 家马 · 驴 · 骡 · 骆驼 · 羊驼 · 水牛 · 牦牛 |
| **取物** | 养着产出 | 蚕 · 蜜蜂 · 水貂 |
| **半驯** | 还留着野性 | 驯鹿 · 鸬鹚 · 猎鹰 · 鹿 |

跨段的按主用途归一，其余用途写进叙事。备选是压成 3 段：同住 / 畜养使役 / 取物半驯。

### 2.3 格子

- 名字公开，不藏问号；参照星座图、省份地图，没拍到也显示名字。
- 三态：未点亮（灰字 +「还没遇到」）/ 已点亮（有照片）/ 已记录（有叙事可读）。
- 每段顶部显示进度，如 `3 / 11`。
- 这是收集清单级别的轻玩法，不额外加稀有度殿堂、集齐奖励或签到。

## 3. 驯化叙事

- 每个驯化种一条：从哪儿来、什么时候、祖先是谁。
- 卡片上做一个「驯养信息」块；是阅读内容，不给任务。
- 文本由我们撰写，不是模型输出。
- 野生近缘如有必要只写一句；有学术争议的用中性措辞或不写。
- 存储位置待定：`apps/api/data/domesticated/` 的 JSON（按 taxonKey）或 `packages/messages`。

---

## 4. 与现有功能的关系

- 名录独立在宠物页，不与野生收录混用。
- 家犬与狼仍是同种两张卡。
- 不新增业务表，不动物种树，不新增树上小环或驯化线。
- 用户可见文案进 `packages/messages`。
