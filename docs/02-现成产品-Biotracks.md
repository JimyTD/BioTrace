## 一句话定位

中科院昆明植物研究所标本馆发起的**公众科学 + 野外记录工具**：强调「个人自然观察地图」「GPS 轨迹 + 沿途照片」「项目协同 / 标本采集」。  
宣传语里有「记录生命之旅」，地图与轨迹比 iNat 更接近你的旅行灵感；整体仍偏**科考/项目记录**，不是年轻人向旅行相册，也没有抽卡。

官网：http://biotracks.cn/  
形态：App（搜「生命观察」/ Biotracks）+ 网页端 + 微信小程序。

## 登录与国内友好度（相对 iNat）

| 点 | Biotracks | iNaturalist（补充） |
|----|-----------|---------------------|
| 注册 | **手机号**（小程序可微信登录） | 官方支持 **邮箱+用户名+密码**；谷歌/Apple 多为快捷登录，**并非唯一方式** |
| 国内获取 | 国内应用商店 / 官网 / 公众号较顺 | 大陆应用商店少见；论坛常讨论访问与地图障碍 |
| 地图 | **高德 + 谷歌**瓦片可切换（城市场景偏高德） | 强依赖国际地图生态，国内体验常不友好 |
| 语言与运营 | 中文为主，国内科研机构背景 | 有简中，但社区与心智偏全球英文生态 |

对你提的「刚需谷歌账户」：若 App 界面主要推 Google 登录，体感确实不友好；严格说 iNat **可用邮箱注册**。  
但对**国内传播/日常使用**，更大障碍往往是：商店获取、网络稳定性、地图服务——Biotracks 在这些点上明显更本土。

## 核心能力

### 1. 快速记录（最贴近「个人随拍」）

- 地图页拍照即可记一条  
- 落在**个人 App 地图**上  
- 偏个人随走随记；教程称速记数据**不宜/不能**随便共享与 Excel 导出（以当时文档为准）  
- 适合：「先留下我的点」，不一定立刻做科研表

### 2. 项目记录（更重、更科研）

- 需进一步**实名认证**（姓名、单位等）才能建/加项目  
- 模板：自然观察 vs 标本采集等  
- 团队协同、统一字段、可导出 Excel  
- 私密等级：公共 / 团队（扫码）/ 私密  
- 心智是「组队做调查」，不是「我的云南旅行画册」

### 3. 地图与轨迹（相对 iNat 的最大差异优势）

- **个人观察地图**：照片打在地图上  
- **GPS 轨迹记录**：走的时候录轨，沿途拍照自动挂到轨迹上  
- 离线地图下载；网页端可上传 GPX/KML，按时间匹配照片  
- 项目地图：热力、聚类、缩略图、3D 等（偏项目数据可视化）  
- 早期定位就明确：旅途邂逅 → 专属自然观察地图 + 行进轨迹 + 沿途图片集  

→ 这比 iNat 的「观察散点」更接近你说的旅行地图相册，但仍是**科考足迹工具感**，不是精美回忆录 UI。

### 4. AI 识别

- 有照片识别（「是什么？」）  
- 可手动改：搜中文名/拉丁名；并可选择鉴定精确到**种还是科/属**  
- **需网络**才出 AI；无网时文档建议先写备注（学名检索曾不支持离线）  
- 识别实力与覆盖：**远不如 iNat 清晰可预期**；机构背景偏植物所，动物/海外细粒度存疑，**必须以你实测为准**  
- 社区体量历史数据约：数万用户级、物种数万级（远小于 iNat 全球规模）

### 5. 其他

- 周边感知：搜物种、看附近图片/轨迹  
- 隐私：图片/轨迹等可设私密（认证相关能力文档有提及）  
- 小程序：微信登录、分享方便、有个人时空统计与地图；偏有网场景  
- **无**：N–UR 抽卡、消费级入侵警示卡、精美旅行叙事相册

## 对照你的硬需求

| 你的标准 | Biotracks 初判 |
|----------|----------------|
| 海外旅行 | **存疑**：宣传有「全球」愿景，生态与识别实际偏国内；海外识别/地图（谷歌层）需实测 |
| 识别 ≥属 | **未知，必须实测**（这是它相对 iNat 最大风险） |
| 地点进识别 | 有位置记录；是否像 iNat 一样强地理加权，文档未强调 |
| 地图/旅程感 | **相对最强现成候选**（轨迹+沿途照片+个人地图） |
| 单 App | 地图记录闭环可能够；若识别弱则仍过不了你的硬门槛 |
| 国内友好 | **明显强于 iNat**（手机号/微信、高德、商店） |
| 入侵警示 / 抽卡 | **无**（与 iNat 同样不满足） |

## 和 iNat 怎么选（第 1 步用）

| | iNaturalist | Biotracks |
|--|-------------|-----------|
| 识别 | 你已觉得强 | 待测，预期通常弱于 iNat |
| 旅行地图/轨迹 | 弱（散点） | **强（轨迹+挂图）** |
| 产品人格 | 全球严肃公民科学 | 国内公众科学 + 野外采集 |
| 国内使用 | 偏不友好 | 友好 |
| 海外 | 强 | 存疑 |
| 旅行相册美学 / 抽卡 | 无 | 无 |

粗线条：

- 若你要「认得准 + 全球」→ iNat 仍更像识别标杆  
- 若你要「走出来的地图回忆」→ Biotracks 更像地图底座  
- **两者都不是**带抽卡/入侵警告的旅行生物图鉴完整体  
- 因你不接受组合：任一单品要结案，必须**自己在识别硬标准上过关**

## 建议实测清单（Biotracks）

同一套材料（含井冈山大蚊 + 若干带 GPS 动物照；若有海外照片更好）：

1. 手机号/小程序能否顺畅注册  
2. 快速记录 → 个人地图是否一眼有「旅途」感  
3. 轨迹：录一段路，拍照是否挂在轨迹上  
4. **识别**：大蚊停在哪一级？动物类群是否经常失败？  
5. 无/弱网：记录是否还能做，识别挂了怎么办  
6. 海外（若可测）：识别与地图是否可用  

打分仍用：认出它｜分类精度｜地图/旅程｜愿长期单用

## 官方性与安全核查（2026-08-03）

### 是否官方？

**是，有明确官方背书**（指中科院昆明植物所相关公众科学项目，不是山寨名牌空壳）：

- 中科院昆明植物所官网新闻多次发布：App 更新、微信小程序等（如 kib.ac.cn / kib.cas.cn 工作进展）
- 学术文献亦引用 Biotracks（http://www.biotracks.cn）为 KIB 相关生物多样性地图/公众科学资源
- 项目域名：`biotracks.cn`；公众号名常见为「Biotracks」
- 常见安卓包名记载：`com.runchance.android.kunappcollect`（第三方下载站标注厂商为昆明植物所标本馆——仍建议以商店/官网为准核对）

### 负面新闻 / 诈骗 / 病毒？

- 公开检索**未发现**针对「生命观察 / Biotracks（昆明植物所）」的主流负面报道、诈骗曝光或明确恶意软件通报。
- 注意英文名撞车：美国大麻监管软件 **BioTrack**（biotrack.com）是另一家公司，其商业/合规争议**与本 App 无关**。

### 手机拦截更可能的原因（不等于已确认有毒）

1. **非应用商店安装**（官网扫码/APK）→ 国产系统常直接拦截「未知来源」  
2. App 需要**持续定位/后台轨迹** → 易被标为高风险权限  
3. 小众科研 App、更新不频繁 → 杀软启发式误报概率更高  
4. **第三方下载站**转载包存在被篡改风险（即使页面写「官方」）

### 更稳妥的试用路径（若仍想测）

1. 优先：微信小程序「生命观察」（昆明所官网曾发文推广）  
2. 其次：苹果 App Store / 华为小米应用宝等搜「生命观察」或「Biotracks」，核对开发者/厂商信息  
3. 避免：来路不明 APK 聚合站  
4. 若必须装 App：看清拦截原文案（未知来源 vs 病毒木马）； sens 权限只开定位与相机必要项

## 用户实测（2026-08-03）

- 识别准确率相对 iNaturalist：**明显更弱**  
- 井冈山大蚊样例：识别为「**长脚蚊**」（中文俗称方向大致对，属大蚊一类叫法；未给出可用的属/种级科学鉴定体验）  
- 对比：Seek → 节肢动物门；Biotracks → 长脚蚊；iNat → 用户认为可用且明显更强  
- 优点：中文用户友好  
- **用户结论：不够优秀，不作为主方案**
