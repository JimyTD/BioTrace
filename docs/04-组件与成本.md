## A. 识别模块（重点）

### 你的判断（采纳）

- 国内几款 App 识别体感弱于豆包类通用视觉 LLM。  
- 愿意 **接入强力模型**，不必自研识别网络。  
- iNat 识别强，但**不能**当「可合法接入的识别 API」。

### 关键事实：iNat 视觉不可直接接入

- iNaturalist **没有**对外公开的 Computer Vision / 识图 API。  
- 其开放 API 主要用于观察数据读写，**不能**把 Seek/iNat 的识图当引擎嵌进你的 App。  
- 结论：iNat 仍是**体验标杆**，不是可插拔组件。

### 候选路线对比

| 路线 | 是什么 | 费用（自用体量） | 优点 | 风险 / 代价 |
|------|--------|------------------|------|-------------|
| **A. 多模态 LLM API**（如豆包/火山方舟视觉理解） | 图片 + 地点/时间 Prompt → 结构化分类 JSON | 个人用量通常极低；常有试用额度；视觉理解曾宣传约「1 元可处理大量 720P 图」量级（以官网实时价为准） | 你已验证豆包级可用；中文好；可塞 GPS 先验；开发快 | 可能一本正经胡说种名；要强制 JSON + 置信 +「只到属」策略 |
| **B. BioCLIP 2（开源）** | 生物基础模型（TreeOfLife 海量图，层次对比学习）；MIT；Hugging Face 可下 | 软件免费；**需要自备 GPU/推理机**（电费/硬件） | 真正为生物视觉训练；适合长期可控、少依赖云厂商 | 部署运维重；端侧难直接塞；零样本仍要配分类名录 |
| **C. 专用免费 API 拼盘** | 植物：Pl@ntNet（免费约 **500 次/天**）；动物无同等完美免费全家桶 | 低用量可 $0 | 植物侧专业 | **动物/全球统一体验差**；要多套逻辑 |
| **D. 商业识物 API**（百度等） | 云识别 | 有个人免费额度，用完按次 | 现成 | 分类深度/旅行场景未必够；长期费用与厂商绑定 |

### 当前倾向（2026-08-04，未百分百锁定）

**更倾向路线 A：云多模态 API。** 详见 `docs/04e-识别选型-倾向记录.md`。

| 角色 | 候选 |
|------|------|
| 更倾向的默认 | **Gemini**（免费层 Flash） |
| 国内值得记录 | **智谱 Flash 视觉**（`glm-4v-flash` 等） |
| 试用/对照 | 豆包、通义 VL（额度向，未测完） |

工程骨架不变：

1. 输入：照片 + EXIF 时间/经纬度（无则省略）  
2. 输出强制 JSON：俗名、学名、分类链、置信、`finest_reliable_rank`  
3. 后处理：GBIF 等校验学名、补全上级阶元  
4. 失败：宁肯停在属 +「待确认」，不硬凑种  

**不推荐当主路径**：接入 iNat 识图；从零训练；只靠传统识物旧模型。

### 关于「国内 App 还没接 LLM」

合理。传统方案是专用小模型 + 封闭名录；LLM 强在**开放世界描述 + 可注入地点上下文**，这正是你井冈山/大蚊案例里豆包能赢 Seek 的原因。  
代价是要工程上管住幻觉（结构化输出 + 分类库校验 + 属级成功线）。

## B. 世界地图模块（重点）

### 原则

不自己画世界地图；用 **开源地图引擎 + 底图瓦片**。

### 推荐栈（尽量 $0）

| 层 | 推荐 | 说明 |
|----|------|------|
| 引擎 SDK | **MapLibre**（Native / GL JS） | Mapbox 开源分支；BSD；无按次 SDK 费 |
| 底图瓦片 | **OpenFreeMap**（公共实例）或自托管同方案 | 基于 OSM；宣称无限请求、无 Key；要保留归属署名；无正式 SLA |
| 备选瓦片 | MapTiler / Mapbox 免费额度 | 有额度上限；超量可能要钱 |
| 逆地理/补地点名 | Nominatim（OSM）等 | 注意限流与使用政策；自用低频通常可接受 |

### 明确不建议当「世界旅行」主底图

| 选项 | 原因 |
|------|------|
| Google Maps | 国内不友好；商业计费；与你「尽量不花钱」冲突 |
| 高德/国内图商单独扛全球 | 海外体验与数据常不如 OSM 系；坐标系（GCJ-02）与照片 WGS-84 还要对齐 |

### 中国坐标注意点（产品层）

- 手机照片 GPS 多为 **WGS-84**。  
- 国内图商常要偏移；**OSM + MapLibre** 用 WGS-84 更省事，适合「国内+海外」一盘棋。  
- 若将来要极强国内路网标注，再考虑双底图，不作为 MVP 必须。

### 地图上你要画的（自己写业务即可）

- 观察点 Marker（照片缩略图/图标）  
- 按旅途分组筛选  
- **不需要**录轨、不需要点连线（第 2 步已 Out）

## D. 成本粗算（个人非营利、低频旅行）

| 项 | 粗估 |
|----|------|
| MapLibre + OpenFreeMap | **$0**（署名） |
| 豆包/火山视觉 API | 自用一年往往可控制在「几乎可忽略～几十元级」（视模型与张数；以控制台为准） |
| Pl@ntNet | 500 次/天免费，自用通常够 |
| BioCLIP 自托管 | 软件 $0；GPU/电费另计（有卡才划算） |
| 自己训练大模型 | **不做** |
