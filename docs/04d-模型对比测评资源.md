# 各家 AI 图文模型：统一测评资源 + 自测建议

> 日期：2026-08-04  
> 目的：帮你用「公开榜 + 自己的几张图」挑云 API，而不是只看广告。  
> 重要：**公开 VLM 榜几乎不测「旅行生物到属/种」**；最终仍要以你的样张为准。

---

## 1. GitHub / 榜单（通用视觉能力）

| 资源 | 链接 | 干什么用 |
|------|------|----------|
| **VLMEvalKit**（OpenCompass） | https://github.com/open-compass/VLMEvalKit | 开源评测套件：200+ 模型、80+ 基准，一条命令跑标准榜 |
| **OpenVLM Leaderboard** | https://huggingface.co/spaces/opencompass/open_vlm_leaderboard | 看各家综合分（MMBench、MMMU、OCR…） |
| 详细结果 JSON | http://opencompass.openxlab.space/assets/OpenVLM.json | 可下载对照 |
| MMBench | https://github.com/open-compass/MMBench | 综合多模态理解 |
| ALL-Bench 汇总 | https://github.com/final-bench/ALL-Bench-Leaderboard | LLM/VLM 等多模态分数汇总（注意来源置信标签） |

**怎么用这些榜：**  
筛「综合视觉强、幻觉相对少」的候选（如 Gemini / GPT / Qwen-VL / 豆包系等），**不能**直接当「大蚊/弹涂鱼识别冠军榜」。

生物细粒度有学术工作用 iNaturalist21 等做 taxonomy-aware 评测（如 CVPR 相关 *Taxonomy-Aware Evaluation of VLMs*），但**不是**现成「一键对比豆包 vs Gemini 识物种」的 GitHub 产品。

**BioCLIP 专用基准**：见 `04a`（TreeOfLife 任务表、RealBirdID）——和通用 VLM 榜是两套世界。

## 2. 更适合「几张自己的图跑各家」的做法

公开套件（VLMEvalKit）偏学术全量评测，**装环境重**，对「5 张旅行图选 API」过重。

更轻的自测路径：

### 推荐：统一 Prompt + 多控制台/脚本

对每张图、每个模型用**同一段中文 Prompt**（强制 JSON 分类链 + 可填地点），记录：

- 最细到哪一级  
- 学名是否离谱  
- 有/无地点时差多少  
- 延迟、是否免费额度内  

建议候选（你有梯子）：

1. 豆包视觉（火山方舟）  
2. 通义 VL（百炼）  
3. Gemini Flash/Pro（AI Studio / API）  
4. （可选）GPT-4o / Claude 视觉  
5. 对照：BioCLIP Demo（已测）

### 可选工具向项目（网关/桥，非物种专用）

| 项目 | 链接 | 说明 |
|------|------|------|
| WebModel / web-model-bridge | https://github.com/linuxhsj/WebModel | 多平台网页模型桥（含豆包/Gemini/Qwen 等），偏「网页能力转 API」，稳定性与 ToS 需自担 |
| 各类 OpenAI-compatible 聚合网关 | 市面较多 | 一个 endpoint 换 `model=` 名，方便脚本 A/B；选信誉好的，注意隐私 |

**最稳妥**：自己写个 50 行脚本，分别调方舟 / 百炼 / Gemini SDK，结果写 CSV——比依赖第三方网页桥更干净。

## 3. 建议你准备的样张包（5～8 张即可）

| 类型 | 作用 |
|------|------|
| 井冈山大蚊（已有） | 难昆虫 + 可测地点纠偏 |
| 弹涂鱼（已有） | 难伪装/背景杂 |
| 常见鸟 1 张 | 细粒度种级压力 |
| 常见花/植物 1 张 | 植物侧 |
| 海外物种 1 张（若有） | 海外硬需求 |
| （可选）模糊/远距离 1 张 | 失败态是否诚实 |

每张跑两遍：**不带地点** / **带 GPS 或地名**。

---

## 4. 统一 Prompt 模板（可直接复制）

```text
你是生物分类助手。根据图片识别生物，并结合下列地点信息（若有）。
地点：{place_name}；坐标：{lat},{lon}；日期：{date}

要求：
1. 只输出 JSON，不要其它文字。
2. 字段：common_name_zh, scientific_name, taxonomy:{kingdom,phylum,class,order,family,genus,species}, confidence_0_to_1, finest_reliable_rank, notes
3. 不确定时 finest_reliable_rank 最高只给到 genus 或 family，species 可为空。
4. 优先考虑该地可能出现的物种，不要编造明显异域种。
```

打分建议（每模型每张 1～5）：认出方向｜属级是否过关｜种级是否靠谱｜是否瞎编｜要不要手改。

## 5. 结论（给选型用）

| 需求 | 建议 |
|------|------|
| 看「谁综合视觉强」 | OpenVLM Leaderboard + VLMEvalKit |
| 看「谁适合 BioTrace」 | **必须自己跑样张**；公开榜只能筛候选 |
| 对比成本 | 免费额度内先跑完样张包再谈付费 |
