## 一、留档的事故：手写 bbox 判国

旧 `settle/country.ts` 是 23 个手写经纬度矩形 + first-match-wins，CN 的矩形覆盖大量邻国且排第一：

| 地点 | 旧实现 | 应为 |
|---|---|---|
| 首尔 37.57, 126.98 | CN | KR |
| 福冈 33.59, 130.40 | CN | JP |
| 河内 21.03, 105.85 | CN | VN |
| 清迈 18.79, 98.99 | CN | TH |
| 新德里 28.61, 77.21 | CN | IN |
| 新加坡 1.35, 103.82 | MY | SG |

`KR` / `VN` / `TW` / `SG` 四条规则是永不命中的死代码；台北当时返回 CN 属**被 bbox 顺序遮住的巧合**，不是正确实现。

影响链路：`country_code` 同时喂 `resolveRarity`（缓存键含国别）与 `resolveIntroducedAlert`（按国名录）——**海外观察的稀有度与引入警示当时全错**。

教训：**核心计算不要用手写地理常量**；这类错误没有报错，只会安静地算错。

## 二、定稿架构（已实现）

- **底图（前端，视觉）**：天地图 `vec_w` + `cva_w` 双 raster；缺 key 回落 OpenFreeMap。仅视觉降级，可以依赖外部 key。
- **国别判定（后端，核心计算）**：天地图逆地理**线上优先** → Natural Earth 10m 国界**点在多边形**兜底。不能只挂在外部 key 上。
- `TW/HK/MO → CN` 归一化**只写一处**（`geo/iso3166.ts`），API 与离线结果都过它。
- `observations.country_source` 记来源（`tianditu | offline | none`），供日后只重跑该重跑的记录。

## 三、天地图实测要点（仍然有用）

**要两个 key，且不可混用**

| 用途 | key 类型 | 说明 |
|---|---|---|
| 瓦片（前端） | **浏览器端** | 配域名白名单；构建时内联，改后必须重新 build |
| 逆地理（后端） | **服务端** | 不需要白名单 |

- 瓦片必须用 `_w` 后缀（EPSG:3857，与 MapLibre 一致）；`_c` 是经纬度投影，接进去会错位。
- 浏览器端 key 只校验 User-Agent 像不像浏览器，**不强制 Referer** → 泄露后伪造 UA 即可用，配额仅 10000/日，**视为敏感信息并定期轮换**。
- 瓦片响应带 `Cache-Control: max-age=432000`（5 天），配额压力远低于预估；实测首屏 18 个请求、一轮典型浏览累计 64。
- 逆地理：`GET https://api.tianditu.gov.cn/geocoder?postStr={'lon':X,'lat':Y,'ver':1}&type=geocode&tk=KEY`，`postStr` **必须百分号编码**，取 `result.addressComponent.nation`。
- 坐标系 CGCS2000 ≈ WGS-84（民用精度），**EXIF 坐标直接用**，无需 GCJ-02 转换（换高德/腾讯就必须转）。
- 必须**显式直连**：`identify/gemini.ts` 用 `setGlobalDispatcher` 装了出境代理，沿用全局 dispatcher 会把国内服务的请求绕去境外。

**逆地理境外覆盖实测（决定「全局 API 优先」而非分区设计）**

| 坐标 | nation |
|---|---|
| 台北 | **中国**（province 台湾省，官方数据天然合规） |
| 柏林 / 曼谷 / 首尔 / 纽约 / 河内 / 伦敦 | 德国 / 泰国 / 韩国 / 美国 / 越南 / 英国 |
| 太平洋海上 | **空字符串**，且 `status:"0"`、`msg:"ok"` |

由此定下两条代码约束：返回的是**中文常用简称**，需「中文国名 → ISO alpha-2」映射表；**「成功但无国家」与「调用失败」必须分开**——海上属前者，直接采信 `null`，不触发离线兜底。

## 四、用量与成本性质

- 逆地理：每张照片 1 次，可按坐标网格缓存；日活 100 × 10 张 ≈ 1000 次/日，远低于任何免费额度。
- 瓦片：日活 100 × 2 次 × 80 瓦片 ≈ 16000 次/日，**费用风险在瓦片，不在 API**。
- 底图选天地图 vs 给 OpenFreeMap 打 style 补丁：前者一次性成本（申请 tk + 配 env），后者是**永久技术债**且只遮观感、不构成合规。

## 五、明确否决过的做法

- 手写 bbox 判国 / 调大阈值搞「弃权逻辑」——换更准的数据，不写弃权。
- 维护 OpenFreeMap style 补丁（仅保留为回落值）。
- 几何 union 合并台港澳（改为判定后归一化，效果一致且省掉布尔运算）。
- 存量数据迁移——所有者确认可全清空，删库重启即可；`DELETE FROM rarity_cache` 也没必要（缓存键含国别，换国别只是去查另一个键，清掉等于白扔已花的 GLM 调用）。
