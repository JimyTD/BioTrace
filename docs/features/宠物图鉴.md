# 宠物图鉴

> 驯养动物另开收集轨，不在种下拆亚种。功能摘要见 [`SPEC.md`](../SPEC.md) §1.9。  
> 更新日期：2026-09-09

家犬折叠键仍是 `Canis lupus`。驯化位把「这只是家犬」和「这只是狼」拆开，避免名录冒领、缓存共座、图鉴同卡。品种是这次遇见的属性，不拆卡、不进 12 题、**不在物种卡上做品种图鉴**。

## 1. 身份与收集

| 层 | 口径 |
|----|------|
| 身份 | 物种键（GBIF 种级折叠）+ 驯化位 + 品种（可空） |
| 收集 | 一张卡 = `(物种键, 驯化位)`。家犬一张，金渐层和没认出品种的都在家猫卡上 |
| 驯化位 | 只认生物本体（家养型 / 品种外观）。项圈、牵引绳、衣服、室内、沙发、食盆不算。流浪犬有家犬形态 → 驯养 |
| 识图 | `domesticated` / `breed_zh` / `dom_evidence_zh`。`null` 折野生；非驯养不留品种 |

`domesticated=true` 写入 `pet_collection_entries`，**不写入** `collectionEntries`。狼和狗同键不同位，两张卡。

## 2. 图鉴入口

- **已收录**混排野生卡与宠物卡。点宠物进家养物种卡，点狼进野生卡。
- 首页「已收录 N」= 两表张数之和。宠物行仍是驯养图鉴入口。
- **物种树**：宠物挂到种级节点，不新开家犬枝。只养狗 → 种级标签「家犬」；狼和狗都有 → 仍一个节点，详情两张卡。见 [`物种树.md`](./物种树.md)。
- **套册**：驯养照常点槽。狼和狗点同一格，不并出两枚。见 [`旅行套册.md`](./旅行套册.md)。

## 3. 判卷

对象是 `(taxonKey, dom)`。缓存键野生 `scale2|{国}|{taxon}`，驯养加 `|dom`。**不升** `scale3`。

- 驯化卷注入 `domesticated=true` / `indoor=false` / `often_absent=false`，这三题不问模型。短窗口、分布窄不锁。
- **名录豁免**：驯养不领保护级 / 三有 / 绝灭（家犬不领狼的二级保护，家鸡不领红原鸡）。徽章同豁免。
- **引入警报不豁免**：按折叠后的种查表。澳洲不产 `Canis lupus`，家犬与狼同种，提示照亮。
- 品种不进 12 题。

观察照打稀有度（开包要用）。宠物卡挂该档，聚合只升不降，另挂「驯养物种」标签。

## 4. 品种（纠偏，不上卡）

对照表在 `apps/api/data/breeds/`（猫 / 犬 / 鸡 / 牛 / 马 + `discard.json`）。库只纠偏，不是许可清单，也不是卡上的品种图鉴。Wikidata 可重复合并：`python scripts/import-breed-wikidata.py`。

拍驯养后看 `breed_zh`，结果写在**该次观察**上（宠物卡遇见列表、观察详情「记录」）：

1. 对上库（标准名 / 英文 / 别名，去末尾「猫犬…」；**唯一包含**才认）→ 展示标准名。
2. 空，或排除表（狸花 / 橘猫 / 三花 / 串串 / 家猫家犬 / 田园猫…）→ **不展示品种**。
3. 其余非空 → 展示模型原文，不进全局 JSON。

不做编辑距离。犬库「中华田园犬」吃田园犬 / 土狗；猫「田园猫」当排除词。

卡上不设品种排。全库预印灰格已否决（猫狗马都不许，也不许按物种开例外）。JSON 里的 `listed` / `prevalence` 不参与展示。

## 5. 旧数据

更新前已拍的照片不回刷。历史行缺省野生，要重识别才进宠物图鉴、离开狼卡。
