# 共享旅途相册

> 几人共同出行 → 一本共享相册。不做全局好友 / Feed / 广场。  
> 功能真源摘要见 [`SPEC.md`](../SPEC.md) §1.8。与管理后台「管理员」无关（团内角色）。  
> 更新日期：2026-08-17

## 1. 行为摘要

| 项 | 结论 |
|----|------|
| 进组 | **共享码**；成员上限 **10** |
| 邀请码 | 每旅途**生成一次**（不换码）；仅管理员可见/复制 |
| 允许加入 | 管理员开关；关闭后持码也进不来；满 10 同样进不来 |
| 管理员 | 创建者初始；可踢人 / 开关加入 / 解散 / 看码；退出则**入团最早**者接任 |
| 识图额度 | **谁传用谁的**（走账号护栏） |
| 删除观察 | **只能删自己上传的**（管理员也不能代删） |
| 相册 | 团员共看；待开包他人可见；**任意成员可点开包**（仪式）；照片仍属上传者 |
| 图鉴/套册 | 任一成员开包成功 → **全体成员**加点；入伙时对历史已开包**全额补算** |
| 离团/踢 | **收回**该旅途共享贡献的图鉴 + 套册槽；自己另有同种开包则保留；不拿别人同种图换封面 |
| 重识别 | 按同一观察最新结果对全体成员广播重算 |
| 地图 | 共享旅途全员落点并入足迹 |
| 解散 | 全员收回共享进度；**各自**建同名私有旅途承接自己的观察（有图才建）；不删他人文件 |
| 文件 ACL | 上传者或同旅途成员可读 |

## 2. 明确不做

- 好友关系、动态 Feed、广场、评论点赞  
- 邀请码定时过期 / 一键换码  
- 管理员代删他人观察、代用他人识图额度
