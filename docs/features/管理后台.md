# 管理后台

> 给运营/维护用的独立产品面，**不是**普通用户「我的」，也不是共享旅途里的「管理员」。  
> 部署入口与引导账号见 [`OPS.md` §8.1](../OPS.md)。  
> 更新日期：2026-08-20

## 1. 定位

| 通道 | 职责 |
|------|------|
| 用户端 | 旅途、识图、开包、图鉴 |
| 共享旅途「管理员」 | 邀请码、踢人、解散（团内角色） |
| **管理后台** | 看全站状态、排障观察、配平台密钥、管存储、管稀有度缓存 |

- 独立账号表 `admin_users`，Cookie `bt_admin_session`，与用户 `bt_session` 隔离。
- 普通用户即使邮箱能登录产品，也进不了 `/admin`。
- UI 实用即可：中文对照表、北京时间；不为换皮做主题。

入口：站点 `/admin`（现网 `http://106.53.188.20/admin`）。

## 3. 页面

| 页 | 做什么 |
|----|--------|
| 总览 | 用户数、识图队列、用户平台配额合计、观察状态、开关、**识图线路**、最近失败、稀有度缓存条数 |
| 用户 | 搜邮箱；详情：配额、自备密钥、重置密码、写入当日用量、清除自备密钥、删除用户 |
| 观察 | 按状态/邮箱/有错误筛选；重入队、重识别、重算开包结算、删除 |
| 稀有度缓存 | 按学名/俗名/分类键/国家查；看判据（得分/模型/采样/12 题答案）；删单条；重判并回写观察与图鉴；批量重算未评物种；清空全部 |
| 平台密钥 | 下拉改 Gemini / TokenHub / 发信 / 天地图 / 模型名 / 日限额；不明文回显 |
| 存储 | 库与上传体积、磁盘内存、备份状态（只读）、孤儿目录、观察缺图 |
| 审计 | 管理员动作流水 |

时间一律北京时间 `年-月-日 时:分:秒`。用户日配额的日期键是 UTC 日，会标「UTC 日」。

### 3.1 用户配额 vs 自备密钥

| 概念 | 含义 |
|------|------|
| 用户平台配额 | 每人每天用平台 Key 识图的次数上限（总览「今日用户识图配额」是全站合计） |
| 自备密钥 | 用户在「我的」改用自己的 OpenAI 兼容接口；不占平台配额，后台可清除 |
| Gemini / TokenHub 次数 | 平台调用供应商的次数（总览识图线路），与用户配额不是一回事 |

### 3.2 识图线路

优先 Gemini；Google **报日额度耗尽** 后冷却约 12 小时，期间走 TokenHub 视觉链（`glm-5v-turbo` → `kimi-k2.6` → `hy-vision-2.0-instruct`，与稀有度共用 `TOKENHUB_API_KEY`）。没有「还剩几次」的查询接口。链实现：[`vl-chain.ts`](../../apps/api/src/identify/vl-chain.ts)。

- **当前线路**：下一张平台识图会先打哪家（与编排器同一套内存健康态）。
- **今日成功/失败**：实际调用次数（UTC 日）；历史成功可从观察的 `identify_provider` 回填。
- **切到 TokenHub**：必须有一次真实识图被 Google 拒绝日额度，才会标记；记下当时 Gemini 成功次数。
- API 重启后内存清空，会再显示 Gemini 并再试；**不要**为了看状态单独打 Gemini 探活。

编排：[`apps/api/src/identify/orchestrator.ts`](../../apps/api/src/identify/orchestrator.ts)；总览快照：[`routing.ts`](../../apps/api/src/identify/routing.ts)。

### 3.3 稀有度缓存

键 `scale1|国家|taxon`（无国家按中国）。命中不问模型，不过期。算法见 [`SPEC.md`](../SPEC.md) §3。

除档位外每行还留**判据**：量表总分、生效模型名、采样次数、名录命中级别；展开一行还能看到
12 题的三态答案、加减明细与模型给的理由。生产走模型链（GLM-5.3 → 5.2 → Kimi k3 → 5.1），
**跨模型答案不完全一致是预期的，不必管**；留这些字段只为一件事——某条档位不合意时，
能看出它是哪档模型、哪一题答歪了，然后单独重判那一行。

| 动作 | 效果 |
|------|------|
| 删除缓存 | 只删这一条。已有观察档位不变；下次结算会重问 |
| 重判并回写 | 立刻问模型，覆盖缓存，并把该物种（该国）已结算/待开包观察和图鉴改成新档。模型链全挂则原缓存不动 |
| 批量重算未评物种 | 只处理还没有量表缓存的物种，幂等，可反复点。每个物种至少 3 次模型调用，默认一次 10 个。**换算法后的老档位「不管它」也是可接受的**，这按钮是想刷新时才用，不是上线必跑步骤 |
| 清空全部 | 核弹。已有观察档位不变 |

观察页「重算开包结算」仍先读缓存，不会单独重问模型。

模型链状态（每档的冷却与最后一次错误）走 `GET /api/admin/rarity-models`。

## 4. 平台密钥

目录驱动：加槽位改 `secret-catalog.ts`，前端下拉跟着走。

保存写入数据目录 `admin-runtime-secrets.json`（与库同级，gitignore），覆盖环境变量；清除覆盖则回落 env。密钥只显示已配置/未配置。

天地图浏览器密钥经 `/api/map/tianditu-keys` 下发，保存后地图下次加载生效，不必重建前端。会话密钥不在此页轮换。

「稀有度」组的 TokenHub 密钥保存即生效，不必重启 API——它是新部署少配了这一项时的补救入口（缺它会全站发临时 SR 而不报错）。

## 5. 存储

- **孤儿目录**：`uploads` 下有以观察 ID 命名的文件夹，库里已无该观察。删除只清磁盘，不删库。
- **观察缺图**：库在、文件不在。只诊断，不自动删库。
- **备份**：若配置了备份目录，只展示最近包；不在后台做恢复。恢复走 [`OPS.md`](../OPS.md) 数据卷操作。

## 6. 明确不做

- 用用户表 `isAdmin` 或用户登录进后台
- JSON 策展编辑器、图鉴/套册玩法后台
- 在后台一键恢复数据库
- 为探测额度去消耗 Gemini 次数
- 管理端换皮 / 复制用户端流程页
