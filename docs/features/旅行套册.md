# 旅行套册（成就系统）

> 产品规格 + 加册手册。实现细节以代码与 [`apps/api/data/volumes/README.md`](../../apps/api/data/volumes/README.md) 为准。  
> 更新日期：2026-08-10

## 1. 定位

| 通道 | 职责 |
|------|------|
| 稀有度 | 单卡炫度（开包） |
| 引入警示 | 当地名录旁路 |
| **旅行套册** | 主题图鉴完成感：槽位点亮 → **整册灰→彩** |

- 成就要精、贴旅途场景；**不做**「满 10/20 种」凑数里程碑、日活连签、首次收集抬稀有度。
- 与稀有度 / 引入 **分通道**；业务册名 **不进** TypeScript 分支。

入口：底栏 **图鉴** → 页顶「旅行套册」。开包收下后若有新点亮/成册，结算页叠短反馈（成册优先于点亮槽；无则静默）。

## 2. 架构（加册不改引擎）

```text
开包 settled
  → GBIF 临时锚定 taxonomy（不改观察落库）
  → taxonomy_in 对槽
  → volume_progress
  → 图鉴列表 / settle.volumes
```

| 部件 | 路径 |
|------|------|
| 引擎 | [`apps/api/src/volumes/`](../../apps/api/src/volumes/) |
| 配置 | [`apps/api/data/volumes/*.json`](../../apps/api/data/volumes/) |
| 文案 | [`packages/messages/src/zh.ts`](../../packages/messages/src/zh.ts)（`volume.*` / `collection.volumes*` / `settle.volume*`） |
| API | `GET /api/volumes`；`POST …/settle` → `volumes.newlyLit` / `newlyCompleted*` |
| UI | 图鉴页套册区；结算短反馈 |
| 冒烟 | `pnpm --filter @biotrace/api volumes:smoke`（规则）；`volumes:resolve-smoke`（GBIF，需网络） |

DSL、GBIF 锚定细节见 [volumes README](../../apps/api/data/volumes/README.md)。

当前唯一规则类型：`taxonomy_in`（拉丁 `rank` + `names[]` + `minReliableRank`）。

## 3. 策展原则（拓展必守）

1. **先场景后人话再规则**：想清楚一次真实出行的画面 → 槽的人话角色 → 科/目/纲名单。
2. **查真实遇见**：赶海/公园/徒步攻略里高频角色，忌拍脑袋拼「海边动物」。
3. **易 / 中 / 难混编**：易槽先亮有进度；难槽 1～2 个封顶，保持整册可凑齐。难 = 更要蹲/翻/等，**不是**点名珍稀种。
4. **生态位不叠**：同一册里同类玩法不双开（如不双开「普通螺 + 普通贝」凑数）。
5. **规则认一类，不点名单种**：例用具体种帮助脑补，匹配的是名单里的阶元拉丁名。
6. **册与册条件尽量错开**：如林缘鸟用科名单，避免与城市「整个 Passeriformes」完全同条件。
7. **文案走术语表**：禁止在业务代码写死用户可见中文。

## 4. 加一册 Checklist

1. 新建 [`apps/api/data/volumes/<id>.json`](../../apps/api/data/volumes/)：`id` / `sort` / `enabled` / `titleKey` / `ledeKey` / `slots[]`。
2. 每个槽：`id`、`titleKey`、`rule`（`taxonomy_in` + 拉丁名单 + `minReliableRank`）。
3. 在 [`zh.ts`](../../packages/messages/src/zh.ts) 增加标题、导语、各槽文案（key 与 JSON 一致）。
4. 跑 `volumes:smoke`；涉及锚定纠错时再跑 `volumes:resolve-smoke`。
5. 更新本文 §5 目录表（便于后人检索）。
6. **不必**改 `apps/api/src/volumes/**`（除非现有 DSL 真撑不住——先讨论再扩引擎）。

关册：配置里 `"enabled": false`（如 `fixture-pipeline`）。

## 5. 当前目录（条件 = 引擎真实匹配）

匹配：GBIF 锚定后的 taxonomy；`finestReliableRank ≥ minReliableRank`；`names` 拉丁名小写相等。例仅便于脑补。

### 5.1 潮间带 `intertidal`（sort 10 · 7 槽）

导语：赶一次礁石潮：从脚边的小螺，到石头下的惊喜。

| 槽 id | 文案 | 条件 | 例 |
|-------|------|------|-----|
| rock_snail | 礁石小螺 | family ∈ Littorinidae, Neritidae, Patellidae, Nacellidae · min=family | 滨螺 |
| barnacle | 藤壶 | family ∈ Balanidae, Chthamalidae, Tetraclitidae · min=family | 藤壶 |
| sea_roach | 海蟑螂一类 | family ∈ Ligiidae · min=family | Ligia |
| shore_crab | 石缝蟹 | family ∈ Grapsidae, Varunidae, Ocypodidae, Sesarmidae, Dotillidae, Macrophthalmidae · min=family | 相手蟹（不含 Portunidae） |
| anemone | 潮池海葵 | order ∈ Actiniaria · min=order | 海葵 |
| hermit | 寄居蟹 | family ∈ Paguridae, Diogenidae, Coenobitidae · min=family | 寄居蟹 |
| echinoderm | 海星或海胆 | class ∈ Asteroidea, Echinoidea · min=class | 海盘车 / 紫海胆 |

未进本册（可另册）：章鱼、滩涂挖蛤/弹涂、海兔。

### 5.2 城市野趣 `urban_wild`（sort 20 · 7 槽）

导语：不出城也能凑一本小图鉴：花坛、墙缝与水边。

| 槽 id | 文案 | 条件 | 例 |
|-------|------|------|-----|
| songbird | 雀形目小鸟 | order ∈ Passeriformes · min=order | 麻雀 |
| flower_bee | 访花蜂 | family ∈ Apidae, Megachilidae, Halictidae · min=family | 意大利蜂 |
| spider | 蜘蛛一类 | order ∈ Araneae · min=order | 园蛛 |
| gecko | 壁虎一类 | family ∈ Gekkonidae · min=family | 多疣壁虎 |
| land_snail | 陆生蜗牛 | family ∈ Bradybaenidae, Camaenidae, Ariophantidae, Hygromiidae, Helicidae · min=family | 巴蜗牛（不含福寿螺） |
| butterfly | 蝶一类 | family ∈ Papilionidae, Pieridae, Nymphalidae, Lycaenidae, Hesperiidae · min=family | 菜粉蝶 |
| frog | 蛙或蟾 | order ∈ Anura · min=order | 泽蛙 |

### 5.3 林缘遇见 `woodland_edge`（sort 30 · 6 槽）

导语：林边道上，从翅翼到偶尔一闪的兽影。

| 槽 id | 文案 | 条件 | 例 |
|-------|------|------|-----|
| forest_bird | 林缘小鸟 | family ∈ Pycnonotidae, Leiothrichidae, Paridae, Corvidae, Timaliidae, Zosteropidae · min=family | 白头鹎 |
| lepidoptera | 蝶或蛾 | order ∈ Lepidoptera · min=order | 凤蝶 / 蛾 |
| odonata | 蜻蜓或豆娘 | order ∈ Odonata · min=order | 红蜻 |
| squirrel | 松鼠 | family ∈ Sciuridae · min=family | 赤腹松鼠 |
| cicada | 蝉 | family ∈ Cicadidae · min=family | 蝉 |
| small_carnivoran | 中小型食肉 | family ∈ Mustelidae, Viverridae, Canidae, Felidae, Procyonidae · min=family | 黄鼬 |

### 5.4 验收册（默认关闭）

`fixture-pipeline`：`enabled: false`，仅管道冒烟，非正式内容。

## 6. 明确不做 / 后置

- 凑数里程碑、稀有度殿堂式「集齐 N 张 SSR」
- 「未计入套册」类提示（系统分不清失败 vs 本就不在册）
- 完整美术封面（现用 CSS 灰→彩占位）
- 套册独立详情页（当前图鉴页展开列表）
- 候选另册：滩涂挖蛤、礁石章鱼高光、地区图鉴等——有场景再配，不抢引擎工期
