# 套册美术分层规范

> 强制：一图一职责；几何对齐靠矢量/CSS，不靠位图「画出来的框」。  
> 资源目录：[`apps/web/public/volumes/`](../../apps/web/public/volumes/)（按皮肤分子目录，默认 `daylight/`）。

## 1. 原则

1. **分层，不合成**：相框、照片、册皮、火漆、仪式底、文案各是一层；禁止「相框+相册/照片」烤进同一张 PNG。
2. **要对齐的东西必须是几何**：邮票内窗、齿孔间距用 SVG/CSS 定数；禁止用不规则 AI 位图当相框。
3. **装饰图只做整块氛围**：册皮插画、仪式纸感底可以是位图；上面再叠 UI，不在图里预留歪斜的「假窗口」。
4. **换布局只动 DOM/CSS**：不重烤资源；换皮肤可换 `volumes/<theme>/` 下的册皮/底/章，框仍共用几何 SVG（或按皮肤换描边色）。
5. **主题可替换**：页面经 [`themes/volumeAssets.ts`](../../apps/web/src/themes/volumeAssets.ts) / [`settleAssets.ts`](../../apps/web/src/themes/settleAssets.ts) 取路径，**禁止**写死 `daylight`。
6. **叠层元件必须透明底**：章、封缄壳、相框等「盖在别的层上」的资源 = **SVG 或 RGBA PNG（alpha）**。禁止带奶油/纸色圆垫的「整章照片」。全幅氛围底（`*-bg.png`、册皮画心）才允许不透明。
7. **章是「引子」不是成品章图**：只提供火漆/邮戳外形与中心留白；档位字、完成文案由 UI 叠字。优先 SVG；位图须抠图。
8. **火漆要像印章**：齿边/双环/刻度等「印模」外形 + 中心留白叠字；禁止滴蜡不规则边。稀有度章用 SVG **mask**；高档「亮」靠**金属高光 / 拉丝纹理 / 辉光**（不是把底色刷浅）。SSR 金、LR 彩虹、UR/XR 釉面高光；XR 另用六角异形章。

## 2. DOM 分层（邮票槽）

```text
.stamp                     ← 格子 1:1
  .stamp-photo             ← 内窗 8% inset；img object-fit:cover
  .stamp-frame             ← stamp-frame.svg（仅框，中心透明）
  .stamp-caption           ← 文案（HTML）
  （可选）.stamp-seal      ← seal-complete.png 角标，绝对定位
```

| 层 | 资源 / 实现 | 禁止 |
|----|-------------|------|
| 照片 | 观察 `coverDisplayUrl` | 画进框 PNG |
| 相框 | `stamp-frame.svg` | 手绘齿孔位图、中心带底图的「空邮票」 |
| 空态 | `plate-<volumeId>-<slotId>.png` 素版印样，缺图退回 CSS 浅纹 | 用带假窗口的复合空印座图 |
| 成册章 | `seal-complete.svg`（引子，中心留白） | 成品章照片、奶油圆垫 |

**内窗定数（与 SVG 一致）**：相对格子 `inset: 8%`（viewBox 上即 `x=8 y=8 w=84 h=84`）。改窗只改 CSS + SVG 一处约定，两处必须同步。

## 3. 其它物件分层

| 物件 | 文件（daylight 例） | 职责 |
|------|---------------------|------|
| 册皮·素版 | `cover-<volumeId>.png` | 仅封面插画，可含书脊感；**无**进度数字、无邮票格 |
| 册皮·彩版 | `cover-<volumeId>-colored.jpg` | 同一幅画手工上色版，集齐后顶替素版 |
| 空槽印样 | `plate-<volumeId>-<slotId>.png` | 单只标本线刻，无框无字，方图 |
| 仪式底·点亮 | `ceremony-slot.jpg` | 上色进行中的场面 |
| 仪式底·成册 | `ceremony-complete.jpg` | 上完色的册子 |
| 成册章 | `seal-complete.svg` | 火漆引子（中心透明叠字） |
| 相框 | `stamp-frame.svg` | 仅几何框 |

仪式弹层推荐结构：

```text
.ceremony
  .ceremony-bg          ← 氛围 PNG
  .ceremony-seal        ← 成册时再叠章（可选）
  .ceremony-copy        ← 标题/正文 HTML
  .ceremony-actions     ← 按钮
```

## 4. 禁止清单

- 不规则齿孔/手绘相框位图用于嵌照片  
- 一张图里同时有相框轮廓 + 照片位 + 文案  
- 仪式底上画好邮票空位再「对齐去贴图」  
- 为微调间距重导出整张复合 PNG（应改 CSS）

## 5. 册皮系列版式（三本必须一致）

三本 `cover-*.png` 共用同一模板，只换画心题材：

- 扁平画板，**不是** 3D 书/圆角实体书脊 mockup（书脊若需要用 CSS）
- 四周约 **8%** 同色纸边；内侧一根细矩形线框
- 画心内：**上约 40% 留白天空**，下约 60% 场景；同一套石版/纸感、同一色系
- 禁止：一本满版、一本带纸边、一本实体书壳混用

出新册皮时以现有任一本为 reference，锁定边距与线框后再改题材。

**素版 / 彩版**：同一块版卖两种货，素版是黑白线刻，彩版是手工上色的贵价本——19 世纪图版书的真实做法。
出彩版时必须以素版为 reference 图，只上色，不许重画构图、不许改线。

**尺寸与格式**：线刻少色，量化成 PNG（512 见方，约 200 KB）；上色图与仪式底是连续调，走 JPEG
（长边 1024，q86）。装配脚本见 [`scripts/install-plate-assets.py`](../../scripts/install-plate-assets.py)，
别把几 MB 的原图直接扔进 public。

### 7.1 抠图流水线（叠层 PNG）

AI 出图**不能**直接给真 alpha。叠层位图统一走 **绿幕 + HSV 色键**（与 [nobg](https://github.com/statico/nobg) / Nano Banana sticker 同思路），**不要**对硬边 kraft 壳用 rembg（会啃边）。

```bash
# 1) 生成时：主体外 + 卡心窗填纯 #00FF00
# 2) 色键入库：
pip install pillow
python scripts/chroma_key_green.py path/to/*-greenscreen.png apps/web/public/settle/daylight/pack-sealed.png
# 或一键：
python scripts/cut_overlay_assets.py
```

章/框优先 SVG **引子**（中心 evenodd 挖空叠字）。验收：棋盘格查看器里四周与卡心窗透明，无奶油圆垫、无黑/绿实心底。

### 7.2 先用静态 HTML 预览叠层（推荐）

单开包 / 套册叠层**不要**只靠看单张 PNG 判断好坏。单图在黑底预览器里常把透明当成「没抠干净」；叠到糊图/纸底上才看得出卡心窗、章引子是否成立。

做法：在 `apps/web/public/<域>/` 下放一份自包含 `preview.html`（内联少量 CSS + 同目录资源路径），用任意静态服务打开，例如：

```bash
# 仓库根或 public 目录起一个静态服即可
python -m http.server 5173 --bind 127.0.0.1
# 打开 http://127.0.0.1:5173/settle/preview.html
```

当前样例：[`apps/web/public/settle/preview.html`](../../apps/web/public/settle/preview.html)（封缄 / 揭示 / 展出可切换）。  
正式页另有 React 预览路由 `/dev/settle-art`（需登录 + `pnpm dev`）；**美术验收优先静态 HTML**，不依赖业务数据与登录。

换皮或新出叠层资源时：先更新 `preview.html` 能过眼，再接到业务页。
