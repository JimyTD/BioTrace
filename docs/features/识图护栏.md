# 识图护栏（账号日额度 + 自备 Key）

> 挡住「注册即可刷爆平台识图 Key」；与供应商侧 Gemini 日额耗尽回退 TokenHub 视觉链是两套概念。  
> 功能真源摘要见 [`SPEC.md`](../SPEC.md) §1.7；后台查看/改配额见 [`管理后台.md`](./管理后台.md)。  
> 更新日期：2026-08-20

## 1. 行为摘要

| 项 | 结论 |
|----|------|
| 日额度 | 默认 **100 / UTC 日 / 账号**；仅消耗**平台** Key 时计数 |
| 环境变量 | `IDENTIFY_DAILY_LIMIT`（`0` = 关闭账号日限额） |
| 扣次 | 平台识图**实际调用**才扣 1（含重识别、失败、不可收集）；排队未跑不扣；自备全程不扣 |
| 超限 | **松**：仍可上传进相册，**不入队识图** → `failed` + `identify_daily_limit`；重识别同理 429 |
| 自备 | 仅 **OpenAI 兼容**（Base URL + API Key + Model）+ 显式开关「使用我的 Key」 |
| 开关开 | 只用自备口；失败**硬失败**，不回落平台 |
| 开关关 | 走平台默认（Gemini → TokenHub 视觉链），计日额度；Key 可留着只关开关 |
| 存储 | 服务端加密（`SESSION_SECRET`）；API 只回已配置 + 后四位 hint；可清除 |
| 前端 | 「我的」：开关 + 三字段 + 今日平台已用/上限 |

## 2. 明确不做

- IP / 全局限流、用量账单看板、多 Key 负载均衡  
- 用户侧厂商预设下拉、模型列表探测  
- 未登录逛壳耗额度

## 4. 与供应商线路的区别

| 概念 | 含义 |
|------|------|
| 用户平台日额度 | 本手册：每人每天用平台 Key 的次数 |
| Gemini 供应商日额 | Google 报耗尽 → 冷却后切 TokenHub 视觉链（见管理后台「识图线路」） |

## 5. 识别软档（影像/标本，2026-09-07 拍板）

> 对象：**真生物但非野外相遇**——宣传海报/画布/屏幕/直播/照片里的照片上的真牛、馆藏标本。
> 不是放行玩具：玩具/手办/雕像（无真实遗体）照旧拦死。

- **模型侧**（[`prompt.ts`](../../apps/api/src/identify/prompt.ts)）：`subject_kind` 新增 `specimen`
  （真实生物遗体标本）；`depiction_or_media` 明确为「真生物的影像/印刷形象」。两类都要求照常给
  俗名/学名/taxonomy/blurb（`kingdom.name_la` 必填），但 `eligibility` 仍 `not_collectible`，
  `ineligibility_reason_zh` 写明非野外相遇。
- **闸门侧**（[`eligibility.ts`](../../apps/api/src/identify/eligibility.ts)）：`depiction_or_media` /
  `specimen` 且**有身份**（俗名或学名非空）且**有界** → 返回软档；无身份或无界 → 照旧
  `identify_not_living` 拦死。`unclear`、人、玩具不变，一律拦死。
- **落库**（[`jobs/identify.ts`](../../apps/api/src/jobs/identify.ts)）：软档 `status=settled` +
  `error=identify_soft_encounter`，全套身份字段保留，国别/地名照判；**不进** `computeSettle`
  （无稀有度/`taxonKey`/`accepted_taxonomy_json`），故不进图鉴、不进套册、不点亮物种树
  （收录硬性要求 `taxonKey && rarity && settled`，软档天然不满足）。
- **前端**：相册 tile 灰徽章「未相遇」（`badge.soft`，非 danger 红）+ 名字；详情页全套识别 UI
  （名字/学名/分类链/简介/标签照常，含保护级别），稀有度徽章位换「NC · 未收录」印章且**置首**
  （[`SoftEncounterSeal.tsx`](../../apps/web/src/components/SoftEncounterSeal.tsx)，代码自绘 SVG），
  照片下方理由说明块；详情页不另加「未相遇」徽章（理由块已覆盖其含义）。
- **标签**：保护级别/引入种标签照常产出（`tagsForNames` 只依赖学名，与 `taxonKey` 无关）。
  软档观察不因脱敏被清标签（`serialize` 仅对 `pending_settle` 脱敏）。
- **历史数据**：旧 `identify_not_living` 行不回刷。重新识别走原路径，额度照扣。
- **文案**：`status.softEncounter`（未相遇）、`detail.softSeal`（NC · 未收录）、
  `error.identifySoftEncounter*`、`detail.softReason*`，均在 `packages/messages` 固定区。
