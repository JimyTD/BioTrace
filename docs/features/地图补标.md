# 无 GPS 地图补标

> **状态：已实现**  
> 更新日期：2026-08-10  
> 实现真源：[`docs/SPEC.md`](../SPEC.md) §1.3；原则见 [`planning/05-技术方案.md`](../planning/05-技术方案.md) B.6。

## 1. 一句话

照片没有 EXIF GPS 时，用户可在地图上把拍摄地对准准星并确认，把观察钉到真实地点，并据此更新国别 / 引入警示 / 稀有度（**不重跑识图**）。

## 2. 已实现要点

| 项 | 落点 |
|----|------|
| API | `PATCH /api/observations/:id/location` |
| 地理下游 | 复用 `computeSettle`（`resolveCountry` / 引入 / 稀有度） |
| analyzing 补标 | 允许；identify 在 settle 前读库最新 lat/lng |
| UI | 详情 CTA → `/observations/:id/pin`（挪地图 + 中心准星 + 确认此处） |
| 底图 | `apps/web/src/map/style.ts`（与足迹图共用；控 zoom；失败回落） |
| 文案 | `packages/messages`：`detail.setLocation` 等 |

## 3. 产品规则（仍有效）

1. **不挡主路径**：上传/识图前不强制补标。  
2. **不靠手打地址**：只地图选点。  
3. **不重跑识图**：不改分类/俗名/学名/`taxonomyJson`。  
4. **已有坐标**：同一接口可改点。  
5. **不做**：录轨/连线、多国 GRIIS 灌库、审图号专项、Android 原生改动。

## 4. 验收（对照 SPEC §1.3）

1. 无 GPS 图 → 识图/开包正常；补标前地图无该点。  
2. 补标国内已知点 → 详情有坐标、地图出现、`countryCode` 合理。  
3. 补标海外（如福冈）→ 国别非误 CN；引入按该国重算。  
4. 补标后分类不变、无需重新开包。
