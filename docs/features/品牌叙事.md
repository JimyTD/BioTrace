# 品牌叙事 · 冲印与显影

本文是品牌层的真源：叙事骨架、用词、图标、色彩分工，以及从现状迁移过去的完整方案。
配套：[`皮肤主题.md`](皮肤主题.md) · [`套册美术分层.md`](套册美术分层.md) · [`旅行套册.md`](旅行套册.md)

预览页：`apps/web/public/brand/preview.html`

---

## 0. 为什么要立这份文档

现有隐喻是拼的：旅途是**相册**、识别是**专家鉴定**、结算是**证书**加**火漆封缄**、收藏是**邮票册**、母皮叫**日光胶片**。
五个物来自五个世界——家庭生活、机构、欧洲书信、集邮、摄影。各自都不差，凑在一起就有拼贴感。

判断一套叙事成不成立的标准：能否不打补丁地回答五个问题——出行是什么、交出照片是什么动作、等待时发生了什么、揭晓那一下是什么、收藏放在哪儿。

## 1. 叙事骨架

| 产品环节 | 叙事对应 | 内部状态（**不改**） |
| --- | --- | --- |
| 一次旅途 | 一卷胶卷 | trip |
| 上传照片 | 拍下这一格、送冲 | observation created |
| 识别中 | 显影中 | `analyzing` |
| 识别完成待结算 | 已显影、待取片 | `pending_settle` |
| 结算揭晓 | 影像在显影液里浮现 | settle |
| 收进图鉴 | 册页、样片墙 | `settled` |

**核心是「显影」这个动作。** 它显的是影像，也是身份——遇见时不知道它叫什么，显影之后它有名字了。
与 slogan「路上遇见的，都有名字」同构。且显影是渐进的，天然适合做揭示动画，不需要「拆封」这种外来动作。

其余机制的归位：

- **稀有度** = 这一格的成色；极稀有档显影时银盐泛虹彩，接得上现有 LR 彩虹徽章
- **引入警示** = 随片附的提示条
- **旅行套册** = 样片墙上待填的空格（邮票墙平移为相片墙，都是带框矩形阵列）

### 1.1 已有的佐证

叙事不是外加的，产品自己已经长向这里：

- 母皮就叫 **日光图版**（`theme.daylight`；2026-08-25 前叫「日光胶片」）
- `apps/web/public/trips/<theme>/film-frame.svg` 资源与 `tripFilmFrameUrl()` helper 早已存在（尚未接入页面）
- 相册页的胶片格、暖米纸底、`--photo-mat` 深色照片垫，全是暗房语汇

见 §7。目前**没有发现必须砍掉的功能**；若后续出现，按约定单独立案，不夹带在视觉改动里。

## 3. 「专家」怎么处理

### 3.1 提案：保留「鉴定」，替换「专家」

- **「鉴定」是动作词**，它解释了 identify 这件事本身，中性、准确，用户已经懂了 → **保留**
- **「专家」是虚构人格**，是拼贴感的来源之一，且与暗房叙事冲突（暗房提供的是场所与工艺，不是人）→ **替换**

替换后，等待的理由从「有个人在看」变成「片子在药水里」。后者更诚实——识别本来就是机器做的，
不需要虚构一个专家来背书，而「显影需要时间」是所有人都接受的物理常识。

### 3.2 冲突排查：重识别

冲印叙事里「一张底片只能显影一次」，与重识别功能看似冲突。
**不成立**：放大印相（enlarging）本就允许用同一张底片再印一张。用词取「再洗一张」即可，功能不动。

## 5. 图标：双档规格

戊与己不是二选一，是繁简梯度的两档。

### 5.1 戊 · 胶片格（大档）

一格 35mm 胶片，齿孔在上下缘，画面里是蜗牛剪影。同时说了摄影、收集、生命三件事。

**用在**：启动图 `@drawable/splash`、`/download` 侧载页 hero、关于页、PWA `512`、未来商店物料。

**必须的工程化改造**（现草案 32px 会糊成方块）：齿孔从每边 5 个减到 3 个并加大、片边加粗、
内窗放大到片宽的 80%、蜗牛占内窗 70%。改造后在 96px 以上使用，不下放到 launcher。

### 5.2 己 · 暗房红蜗牛（小档）

去掉容器，只留蜗牛剪影。

**用在**：Android 自适应图标、各密度 legacy mipmap、favicon 16/32、Web 顶栏小标记。

**工程实现最干净**：自适应图标本就是两层——
`values/ic_launcher_background.xml` 由 `<color>#FFFFFF</color>` 改为 `<color>#7E2B2E</color>`，
前景 `ic_launcher_foreground` 换成奶油蜗牛，结构不动。

**待修**：壳内圈缝隙偏细，32px 以下会粘连，需加粗留白。

### 5.3 繁档保留

B 版雕版邮票转为页面 Logo，用于社交分享图与对外物料。符号内核仍是同一只蜗牛。

## 6. 色彩分工

引入**标识色**与**行动色**的分工，两者不再混为一谈。

| 角色 | 值 | 职责 |
| --- | --- | --- |
| 标识色 `--brand` | `#7E2B2E` 暗房红 | 图标底、启动图、品牌物料。大面积、低明度 |
| 行动色 `--cta` | `#d3543c` 胶片橙 | 按钮、激活态、成册线。小面积、高饱和。**不变** |

暗房安全灯是唯一一种在黑暗里也不会毁掉影像的光——与「安静地把遇见冲洗出来」同构。
它与胶片橙同色系，并置不打架，且有出处，不是借来的。

**注意**：`--accent #3a322c` 是暖褐深字，不是品牌色。新增皮肤时勿误用。

## 7. 待拍板：「证书」这个词

`settle.title` 现为「鉴定证书」，`collection.lede` 为「收下的证书，都在这里」。
「证书」承载的是**权威命名**的心智——用户收藏的是「一份被认定的身份」。

- **改为「定名样片」**：进入叙事，但「证书」的权威感减弱
- **保留「证书」**：心智锚点不动，但它是机构语汇，与暗房有轻微不谐

我倾向改，因为「样片」同样能承载命名（样片背面就是写学名的地方），而且「洗出来的」比「收下的证书」更有温度。
但这是本方案里唯一会改变用户心智锚点的一处，需你确认。

## 9. 分期落地

**第一期 · 零风险**：不动任何文案与业务代码，只补品牌资产。
Android 自适应图标两层、各密度 mipmap、favicon、PWA manifest、启动图与 `--bg0` 对色
（`capacitor.config.js` 现为 `#f4f1ea`，应对齐 `#f3efe7`）、各 `package.json` 的 `description`。

**第二期 · 文案迁移**：按 §4 改 `packages/messages/src/zh.ts`，单独一个提交，可整体回滚。不动 API。

**第三期 · 结算页美术**：按 §8 重出结算相关位图，开包动画从「拆封」改为「显影浮现」。

**第四期 · 套册视觉**：邮票墙调为样片墙，接入 `film-frame.svg`。

**第五期 · 可选**：以蓝晒（氰版）替换 `tide` 作为第二皮肤。工艺即皮肤——
日光胶片是显影盘里浮现，蓝晒是阳光下变普鲁士蓝，湿版火棉胶是玻璃板银灰，即时片是白边摇一摇。
同一骨架，不同显影方式，天然满足「不同主题不同包装」。

## 11. 已落地：暗房作为第三皮肤（2026-08-25）

本方案没有整体改写产品，而是先做成一套可切换的皮肤 `darkroom`「暗房」，在真机上验证叙事成不成立。

**落了什么**

- 深色 token 一套（`themes/darkroom.css`），行动色取安全灯红 `#c14a3c`，照片垫压到 `#0c0908`
- 资源包 15 件齐全：三本册皮重画为低调子暗房印相；`stamp-frame.svg` 去齿孔改相纸白边；
  `film-frame.svg` 保留齿孔（旅途仍是一卷胶卷）；`pack-sealed.png` 由封缄牛皮纸改为未显影的空白相纸；
  仪式底改为安全灯下的晾片房；壳纸纹接上暗房墙面颗粒
- §4 用词表作为 voice 覆盖表接入，切皮肤即换词

**顺手补的机制**（三套皮肤共同受益，见 [`皮肤主题.md`](./皮肤主题.md)）

- `THEME_META` 登记表：明暗 scheme、自备资源域、包装用词
- 资源域缺失自动回退默认皮肤，新皮肤可以只出一部分图先上
- `styles.css` 残留的日光橙、写死的 LR 彩虹渐变、危险按钮白字全部 token 化
- 地图简图配色随皮肤明暗切换，深色皮肤下不再甩出一张亮白纸地图

**还没做**：Android 图标与启动图仍是 Capacitor 默认（§5、§9 第一期）；`settle.title` 用「证书」还是「样片」的全局取舍仍未拍板（§7），目前只在暗房皮肤内用「定名样片」。

## 10. 禁止

- 为换叙事改动 `analyzing` / `pending_settle` / `settled` 等内部状态码
- 在 `apps/web` / `apps/api` 业务代码里写死本文的中文用词，一律走 message key
- 在 `pages/*` 写死 `#7E2B2E`；标识色须落 `themes/<id>.css` 的 token
- 把标识色与行动色混用，或用标识色替换 `--cta`
- 借视觉改动之名删减功能；任何功能取舍单独立案
