## 关键约束（用户答复，2026-08-03）

1. **地理范围**：必须覆盖**海外旅行**（不仅中国）。  
2. **分类精度（硬需求）**：可接受的模糊最多到**属**；到「种」最好。  
   - 不可接受：停在目/科等过粗层级（例：「这是个螃蟹」无意义）。  
3. **组合使用**：几乎不接受双 App / 多工具拼凑。  
   - 只要出现「必须组合才能用」，倾向自研；除非确认开发不出来。

### 需求闭环（对照基准）

1. 拍照 / 上传  
2. AI 识别 + 分类学信息（至少到属，理想到种；最好有界→种链路展示）  
3. 地理锚定（照片 GPS / 位置 → 地图）  
4. 旅行向回看（时间轴 + 地图轨迹 / 旅程图鉴感）  
5. **单 App 闭环**（由约束 3 新增为硬条件）

### 第 1 步正式结论

1. **不存在完美满足灵感的现成单品**（识别够用 ⊕ 旅行相册/旅程图鉴 ⊕ 单 App ⊕ 海外 ⊕ 属级精度）。  
2. **Seek / Biotracks** 不作为主方案；组合方案不作为结案路径。  
3. **iNaturalist** 是已测产品中**唯一识别达到「可用」**者，可作为能力标杆与临时记录工具，但：  
   - 无旅行相册叙事  
   - 人格偏严肃公民科学  
   - 国内登录/商店/地图体验不友好  
   - 无入侵警示体验、无 N–UR 抽卡收集感  
4. 因此：**讨论不终止于「直接用某 App」**；进入 **第 2 步：辨明需求**（必须 / 有趣 / 做不到 / 如何辅助），再谈是否自研及如何借用组件。  
5. 潜在差异点（待第 2 步定优先级）：旅行地图相册、入侵种警示、抽卡收集感；地点作为识别输入。  
6. **生物记**（动物所）用户补测：识别合格但分类太粗 → 不改变第 1 步结案，亦不升格为候选。

## 实测记录

### Seek 试用 #1（2026-08-03）

- **原图**：清晰俯拍长足双翅目昆虫（形态上高度疑似大蚊/鹤虻一类；翅脉可见）
- **实况补充（用户）**：井冈山区拍摄；死去个体置于地面特写；已接近民用相机可用极限，但主体与翅脉仍可读
- **Seek 输出**：`Arthropods`（节肢动物门级）+ 明示无法给出确切物种
- **对照硬标准**：要求最粗到**属**，理想到**种**  
- **人工/通用模型对照**：
  - 对话助手仅凭原图可稳到**大蚊科 Tipulidae**，属倾向 *Tipula*（种级仍不宜武断）
  - 用户称豆包（非最强模型）亦答对
  - 使用场景下照片**自带地址**，可大幅收缩候选（本例：井冈山 → 排除大量异域类群）
- **判定**：**不满意，且属明显不及格**——不是「种太难」，而是连科/属都没给出；门级对本需求无信息价值
- **产品含义（第 1 步）**：
  1. 不能默认「Seek = 识别硬需求已解决」
