# 第 2 步：需求辨明

> **状态：已结案并冻结**（2026-08-03，用户确认进入第 3 步）。这里是「当初为什么这样定」，**实现状态看 [`SPEC.md`](../SPEC.md)**。  
> 不写技术方案、不选开源组件（第 3–4 步）。

## 0. 产品一句话（已定稿）

> 记录旅行中遇见的生命（动物/植物/菌等）：选一张带信息的照片即可识别到尽量细的分类并展示分类链，自动落到地图与旅程里，形成可回看的个人生物旅行图鉴。

## 1. 分层定义

| 层级 | 含义 |
|------|------|
| **P0 必须** | 没有就不成立 |
| **P1 第一版要有** | 与闭环一起交付（可稍晚几天做完，不能砍掉） |
| **P2 可后置** | 有更好，不挡「能用」 |
| **Out** | 明确不做 |
| **Hard** | 难完美；靠辅助策略，不假装百分百 |

## 2. 需求清单（按你的答复更新）

### P0 必须

| ID | 需求 | 说明 |
|----|------|------|
| M1 | 拍照或相册选图 → 一条观察 | 主路径像 iNat：**选图即可** |
| M2 | 时间+位置默认从 **EXIF/GPS 自动读** | 无定位时再点地图补标；**不靠手打地址** |
| M3 | 识别尽量准；可接受最粗到**属**；展示分类链 | 种级尽力；粗于属要明示失败/待确认 |
| M4 | 观察自动落在地图上，可浏览 | 点状即可 |
| M5 | 列表/时间回看个人图鉴 | — |
| M6 | **单 App** 完成闭环 | 已拍板 |
| M7 | **海外 + 国内** | 已拍板 |
| M8 | 个人向：默认可私密，不强制社区 | 非第二个 iNat；社交为可选后置，非产品禁忌 |
| M9 | **动物 + 植物 + 菌等**都要 | 已拍板 |
| M10 | **自动化程度高** | 少操作：选图 → 出识别与落点 |

### P1 第一版要有（你已说「做」/「需要」）

| ID | 需求 | 说明 |
|----|------|------|
| W1 | **旅途分组（用户自建）** | 如「井冈山 2026」；把观察归入一次旅途。旅行相册要这个，**不要**录轨/连线 |
| W3 | 手改分类 | AI 错了可纠正 |
| W4 | 识别使用地点（+时间）辅助 | 理想仍来自照片自动信息 |
| W5 | 失败态诚实 | 不硬凑种名 |
| F1 | **入侵/关注物种警示** | 第一版做；难在按地区名录靠谱，不在 UI 本身 |
| F2 | **抽卡 / N–UR 收集感** | 第一版做；难在稀有度规则可解释 |

### P2 可后置

| ID | 需求 | 说明 |
|----|------|------|
| F3 | 精美分享图（单条/一趟旅途） | 与日后轻社交同一演进线 |
| F4 | 七级分类的更强视觉包装（P0 已要求有链，P2 是「更好看」） | — |
| F5 | 轻社交 / Feed / 看他人观察 | **愿望保留**；本阶段不做是因为容量与审核吃不下，不是路线放弃 |

### Out 明确不做

| ID | 不做 | 理由 |
|----|------|------|
| X1 | 强制社区鉴定 / 第二个 iNat | 人格不同（≠ 不做任何社交） |
| X2 | 第一版实时 AR 镜头识别 | 非必须 |
| X3 | 标本采集字段 / GBIF 科研向 | 非主场景 |
| X6 | 连续 GPS 录轨（航旅纵横/徒步轨） | 你明确不需要 |
| X7 | 地图观察点连线 | 非必须 |

## 3. Hard 与辅助策略（已约定）

| 难点 | 策略 |
|------|------|
| H1 种级 | **成功线 = 属**；种为加成；低置信不硬凑 |
| H2 难认对象 | 允许多图/手改/「待确认」 |
| H3 全球覆盖 | 不承诺种级全球完美；体感对齐「可用的 iNat 级」而非 Seek/生物记 |
| H4 入侵警示 | 按**观察地点 + 权威/公开名录**触发；文案可用「当地关注/引入种」若「入侵」争议大 |
| H5 抽卡稀有度 | 规则可解释（如分布、类群罕见度、旅途内首次等），允许日后调整 |
| H6 成本 | 需求层只约定：尽量不花钱；具体引擎放第 3 步 |

## 4. 验收标准（用你的话整理）

你怎样算满意：

> **具备 iNat 那类基础能力**（选图自动带时空、识别较准、能到较细分类、地图上能看到自己的点），**再加上**自建旅途分组的旅行相册、抽卡收集、入侵/关注种警示等定制小功能；整体自动化高、少折腾。

对照检查：

- [ ] 一次国内或海外出行：相册选图 → 多数能到属或种，自动上地图  
- [ ] 能把这些观察放进自建「某次旅途」里回看  
- [ ] 抽卡与警示在第一版可见、可用（规则可先简单）  
- [ ] 不需要第二个 App 才能完成上述流程  

---

## 5. 与第 1 步的衔接

| 现成产品 | 关系 |
|----------|------|
| iNaturalist | **能力标杆**（基础记录+识别）；缺旅途相册/抽卡/警示，国内不友好 → 非终局 |
| Seek / Biotracks / 生物记 | 不主推 |

第 2 步结论导向：需要自建（或二次开发）一个**单 App**，吸收 iNat 级基础体验 + 你的旅行向定制；组件与成本见第 3 步。
