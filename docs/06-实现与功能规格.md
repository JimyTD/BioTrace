## 1.1 识图韧性

- **串行队列**（默认 concurrency=1），避免免费层被并行打爆。
- **Gemini 健康态**（进程内）：短限流 → 保持 `analyzing` 等待（≤90s）再试；日额耗尽/长冷却 → **切智谱 GLM**。
- 两侧都不可用才 `failed`，文案温和（不提配额/账单）。
- Me / `/api/health` 可看 Gemini、智谱配置与冷却状态。

## 1.2 识图合格性闸门

在开包 / 稀有度 / 图鉴之前拦截「不是现场活体生物」的结果（书、人、玩具、卡通等）。

- Prompt 要求模型声明 `subject_kind` / `subject_living` / `eligibility`；代码：[`eligibility.ts`](../apps/api/src/identify/eligibility.ts)。
- **可收集**：`living_organism` 且活体（含饲养/动物园）。
- **不可收集**：人、玩具/模型、影像/印刷形象、无生物、不明；写 `failed` + 分型码，**清空**俗名/学名/taxonomy/稀有度/`taxonKey`，不开包、不进图鉴。
- 用户主文案（术语表）：**「东西是旧的，没用。」**（`error.identifyNotCollectible`）+ 副句换活体照片；徽章「不可收集」。
- 过粗（真生物但粗于科）仍用 `identify_too_coarse`，不用听泉梗。
- 详情可点进：不合格不渲染分类链，不因脏字段报错。

验收：书 / 卡通人 / 玩具熊 → 不可收集 + 梗句 + 无分类；真鸟可开包；过粗仍「未理想识别」。

## 3. Cut 3：稀有度与名录

### 3.1 理念（2026-08-07 换维）

稀有度 = **旅行抽卡遇见价值**。主路径**不再**是 GBIF count，也**不再**是 `ax+by+cz` 加权。

- **主信号**：GLM/识图给出 `encounter_class`（遇见类别分桶）。
- **否决**：`pest_weed` / `everyday` → 强制 **N**（蟑螂难拍也不能抬档）；`unobtainable` → **XR**（近乎不可能兜底）。
- **小修正**：成群/半驯化仅对 SSR+ 降 1 档；保护级仅对 SR/SSR 最多升 1 档。
- 档位：`N → R → SR → SSR → UR → LR → XR`。
- 代码：[`formula.ts`](../apps/api/src/rarity/formula.ts) + [`rarity-score-config.json`](../apps/api/data/rarity-score-config.json)。
- 标定：`pnpm exec tsx scripts/rarity-calibrate.ts`（在 `apps/api`）。无物种背答案 prompt 约 **exact 15/26、≤1 档 24/26**。
- **结算主路径已接线**：识图后 `computeSettle` → `resolveRarity` → GLM `encounter_class` → `resolveFromEncounter`；缓存键 `enc|国家|taxon`。

| encounter_class | 基础档 |
|-----------------|--------|
| pest_weed / everyday | N |
| place_common | R |
| noteworthy | SR |
| scarce | SSR |
| hard | UR |
| legend | LR |
| unobtainable | XR |

### 3.2 旧路径

- GBIF count 分级不再被结算调用；[`rarity-thresholds.json`](../apps/api/data/rarity-thresholds.json) 仅历史/脚本参考。
- GLM 失败时回退 seed → 默认 **R**（默认不落库缓存）。

### 3.3 环境变量

| 变量 | 默认 | 含义 |
|------|------|------|
| `ZHIPU_API_KEY` | — | 稀有度 encounter 打分（文本）与识图回退 |
| `ZHIPU_TEXT_MODEL` | `glm-4-flash` | encounter_class 文本模型 |
| `RARITY_CACHE_TTL_DAYS` | `30` | encounter 缓存 TTL |
| `GBIF_ENABLED` | `1` | 遗留；结算主路径已不读 |

### 3.4 引入名录

- [`introduced-seed.json`](../apps/api/data/introduced-seed.json)：手写策展；与稀有度**分通道**。
- 有国家码且学名/taxonKey 命中才警示；无 GPS 不警示。

## 5. Cut 5：邮箱魔法链接（代码已收口）

- 发信：**Resend**（`RESEND_API_KEY` + `MAIL_FROM`）；`APP_ORIGIN` 为站点公网源（魔法链接与跳转）。
- `POST /api/auth/request-link` → 邮件链接 → `GET /api/auth/verify?token=` 设 cookie 后重定向首页。
- Token：sha256 入库、15 分钟、单次；同邮箱/IP 内存限流。
- 本机可 `DEV_AUTH=1`；无 Resend Key 时链接打 API 日志。
- **上线运维（非再写功能）**：在 `deploy/.env.production` 填 Resend；**`DEV_AUTH=0`**；`APP_ORIGIN`/`CORS_ORIGIN` 指向正式域名。部署 agent 按 `docs/07` 勾验收即可。
