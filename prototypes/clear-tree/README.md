# 物种树原型与走查材料

> **临时目录，不是生产代码。** 正式实现在 `apps/web/src/tree/` 与
> `apps/web/src/components/SpeciesTree3D.tsx`。
>
> 这里的东西留着有两个用途：**视觉基准**（正式实现照它调）和
> **快速试错场**（改渲染参数不必启动整个前端）。
>
> 落地记录与交接说明：[`docs/wip/物种树-3D落地与临时决策.md`](../../docs/wip/物种树-3D落地与临时决策.md)

## 怎么看

这些是纯静态 HTML，但**必须用 http 打开**（WebGL 在 `file://` 下会被部分浏览器拦）：

```bash
cd prototypes
python -m http.server 8099
# 然后开 http://127.0.0.1:8099/clear-tree/device.html
```

## 文件

| 文件 | 是什么 |
|---|---|
| **`v2-roots.html`** | **视觉基准。** 三段式布局（树冠 / 近地 / 根系）的交互原型，单文件约 1900 行 vanilla WebGL2。正式实现是从它移植的 |
| `device.html` | **手机尺寸预览。** 六种机型 + 横竖屏 + 并排对比桌面。关键：缩放作用在外层，iframe 里的 `innerWidth` 是**真实值**（393 而非缩放后），所以页面自己的响应式计算（`SQ` 压缩、标签排布）是真的 |
| `v1-canopy.html` | 早期版本：只有树冠、没有根系。留作对照 |
| `index.html` | v1 的旧副本，已无用 —— 可删 |

### `v2-roots.html` 的实验开关

```
?fan=50     让动物界的第一个「科」下带 50 个属，并自动跳进去
            用来测大扇出的形态与标签取舍。任意数量（上限 200）
```

## `shots/` 里的图

都是走查时为了**避免凭单张截图下结论**而做的等价对照。留着是因为每一张都对应一个当时判断错了的问题。

| 图 | 说明 |
|---|---|
| `tree-live.png` | 正式工程里跑起来的样子（PC 1440×860，空收集态） |
| `tree-chordata.png` | 展开脊索动物门（手机 393×852）。**这张是「子级 rank 不统一」的实证** —— 「哺乳纲」和「喉盘鱼目」并列在同一屏 |
| `fanout-fix.png` | 标签取舍改造的前后对比（16 属崩溃 → 修复 → 50 属）。左格是「碰撞就往下顶」的结果：标签叠成一竖列、脱离自己的枝、盖住整棵树 |
| `root-compare.png` | 宽窗口 vs 手机竖屏的**等高**对比。做这张是因为我第一次用了不等比缩放，把放大假象当成了「根系形态变差」，误报了一个不存在的问题 |

> 教训（也写进了交接文档）：**只要打算说「某处变差了」，先做等价对照。**
> 不等比的并排缩放会制造出根本不存在的问题。
