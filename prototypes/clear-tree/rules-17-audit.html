一、文案纪律（C1–C8）

#原文判断去向理由
C1 尽量不用句号（短句 / 状态 / 提示 / 按钮一律无句号；仅「多个各自独立、缺了看不懂的信息单元」才用句号） 改撰写规范 方向对，但「尽量」是软的、范围含糊，我把它当过硬线，砍出过干瘪句。窄化成：按钮 / 标签 / 状态 / 短提示不带句号；完整句子该带就带。
C2 禁同义反复 砍— 「反复」的界没人能划。我用它砍掉过好句（「界面轻到几乎不见」——那是补画面，不是重复）。留着只会变成一把乱刀。
C3 亲切短句优于完整陈述 砍— 这就是「大白话」的源头：把「亲切」和「短」划等号，逼出一堆没文气的句子。亲切 ≠ 短 ≠ 好。
C4 说明性文案过「存在意义」三问，皆否 → 删 改撰写规范 三问对说明性 / 机制性文案有用；但我拿它去否定修辞（「识万物」）就成了凶器。限定：只管说明性文案，不得用于判定 slogan / lede / 修辞。
C5 事实正确 ≠ 需要告诉用户 留撰写规范 真的、有用，不干扰创作。
C6 与界面已有元素重复的文字删 留撰写规范 有用；但标「软」——容易过头。
C7 提案至少覆盖「该删 / 该合并 / 该改措辞」三类 留进度文档 它是审查方法，不是撰写规则——不该进撰写规范。
C8 判据用于淘汰，不用于生成 留撰写规范·置顶 最关键的一条。它正是 C1–C4 被误用的解药：尺子只用来淘汰，造句时把它放下。
