# 壳静态美术

按皮肤：`daylight/`、`tide/`。

顶栏 / 底栏的骨架在 `styles.css`（固定高、四项文字、主区单独滚动）。**纸纹是成品的一部分**：日常页不是纯色 hex。

| 文件 | 类型 | 职责 |
|------|------|------|
| `page-texture.jpg` | 可选整幅衬纸 | 默认不用。日常页用 `--bg-atmosphere`，避免整页贴纸照片 |

约束：

- 不要把邮戳、Tab 图标、文案画进这张图；点击热区与四项路由不变
- 路径写在对应 `themes/<id>.css`，禁止页面写死 `/shell/daylight/`
