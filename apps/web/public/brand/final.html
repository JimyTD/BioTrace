BioTrace

路上遇见的，都有名字

三档标记

同一只蜗牛，同一套齿孔语言，从繁到简。三档都是双色，没有渐变、没有描边、没有投影。

桌面图标

自适应图标两层：背景层纯色 #2F4A3C（values/ic_launcher_background.xml）， 前景层是奶油色的胶片条与蜗牛（mipmap-*/ic_launcher_foreground.png，五档密度）。 同一枚图标固定不变，不随皮肤切换——桌面图标是产品在 App 之外的身份。 位图由 scripts/brand-export.py 从本页这几个 SVG 导出，改形状改矢量再重导。

大档的用法

色与字

书布绿#2F4A3C 标识色。图标底、启动图、品牌物料。大面积、低明度
纸奶油#EFE9D8 形色。蜗牛、齿孔带、品牌物料上的字

字用 Outfit（App 里 --font-brand 已经是它）。 这两色只在 App 之外露面——桌面图标、启动图、侧载页、分享图。 进不到任何皮肤的 token 里，皮肤内部的配色与行动色照旧各管各的。

Slogan

路上遇见的，都有名字。

正本在 messages 的 app.tagline（原值「旅行自然观察」是品类描述，不是 slogan）。
它不是新编的：settle.lede 现在就是「这趟遇见的生命，现在有名字了」， 「遇见」在整张文案表里反复出现。一句话说清出门与定名两头，和蜗牛也同构——背着房子在路上。
index.html 的 meta 与 manifest.webmanifest 各抄了一份： 它们在 React 起来之前就要被爬虫和安装器读走，取不到 t()。
