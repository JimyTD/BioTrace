# 图鉴视觉草案

入口：`/devpages/collection-concept.html`。草案独立入口继续保留；获准的走片现已迁入正式 `/collection`，草案直接复用 `components/CollectionReel.tsx`、`CollectionReelCard.tsx` 与正式主题 / 结构样式，不维护第二套走片实现。

长期保留：这是正式走片的视觉对照与边界走查入口；当前所有文件和入口均已入库，不依赖未跟踪资源。

- 清透主稿：中等尺寸的连续走片带，卡纸下沿名称 / 学名 / 稀有度；下方保持静止的宠物与物种树入口。完整目录仍用照片网格。
- 日光：相同结构与行为，较直的纸边、图版分隔线与衬线学名。没有第二份页面逻辑。
- `main.tsx` 仅承载草案浏览；数据类型、检索排序、树、标签与资源 helper 复用正式实现。
- `clear.css` / `daylight.css` 分别赋值草案 token，`layout.css` / `conveyor.css` 只管结构。
- 默认示例照片来自已有走查资源，宠物图来自 `prototypes/pets-page`；不是识别结果，也不写进用户收录。
- 顶部可切到本地账号的只读收录；不写数据库、不保存账号外观。主题切换使用 `applyTheme`，仅影响本机首屏缓存。

草案中的照片、全部收录、搜索、排序、宠物、物种树和返回均可操作。详情用于检查大图与标注，不复制观察修改、删除或识图流程。

走查参数：`?theme=clear|daylight&data=sample|live`；示例数据可附加 `state=empty|single|long|large` 检查边界，`large` 为 5000 条元数据。手机基准为 390×844，另测 320 窄屏及 1280 桌面。

## 走片行为

- 按收录条目循环，不挑代表，不把每张原始照片都放进队列。只渲染可见区域加两侧缓冲，5000 条不会生成 5000 个图片节点。
- 自动速度为 14px/s；悬停、键盘聚焦、按住、页面不可见或走片区离屏时停止。减动偏好下只保留手动拖动和前后翻片。
- 横向拖动与页面纵向滚动分离；拖动后拦截误触点击。键盘可聚焦走片区后用方向键换片，也可逐张聚焦链接。
- 本机按示例 / 本地数据分别记录条目 key、片内偏移与暂停选择。返回或刷新后续播；新增条目改变顺序时仍按 key 找回位置。
- 条目能一次摆下时不重复凑片；零条显示原空态，单条不自动移动。
- 两套已登记皮肤都用同一种走片行为，差异仅在纸边、刻度和控件颜色，因此不新增无差别生产槽位。若后续某套主题需要完全不同的演法，再提取表现槽位。
- 正式页另有按账号的缓存与续播隔离；从走片进入野生 / 宠物种卡后，图鉴来源会一直保留到观察详情返回。后台刷新按条目 key 对齐位置，失败保留旧快照并提供重新加载。

逻辑校验：`pnpm.cmd --filter @biotrace/api exec tsx ../../scripts/walkthrough/reel-check.ts`。
`?motion=reduce` 可在不修改操作系统偏好的情况下走查减动分支；不传时按真实 `prefers-reduced-motion` 生效。
