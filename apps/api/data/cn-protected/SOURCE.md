# 中国国家重点保护野生动物名录（本地表）

法律依据：国家林业和草原局、农业农村部公告 **2021 年第 3 号**，2021-02-01 施行。

官方文本是扫描 PDF（理光复印），中国政府网与林草局文件哈希相同，**没有开放「学名→等级」接口**。

| 文件 | 角色 | 是否入库 |
|---|---|---|
| `govcn.pdf` | 中国政府网公告附件原件 | 否，见下方地址 |
| `ahwca-2021.html` | 安徽省野生动植物保护协会转载的同名录表格（用来抽字） | 否，见下方地址 |
| `list.json` | 从该 HTML 解析出的结构化表 | **是**（评分依据） |

原始件体积大且是公开文件，不入 git（见 `.gitignore`）。要重跑解析先下回本目录：

- 政府网附件：<https://www.gov.cn/zhengce/2021-02/05/5727412/files/7bf5c0b21f554df497f370068f027ddb.pdf> → 存为 `govcn.pdf`
- 林草局同文件（哈希相同，备用）：<https://www.forestry.gov.cn/html/main/main_5461/20210205122418860831352/file/20210205151950336764982.pdf>
- 可抽字的转载页：<http://ahwca.org.cn/News/detial.aspx?category_id=120&id=220> → 存为 `ahwca-2021.html`

公告种数：980 种 + 8 类；一级 234 种 + 1 类；二级 746 种 + 7 类。  
解析结果：988 行 = 235 一级 + 753 二级，与公告加总一致。

`list.json` 由 `apps/api/scripts/parse-cn-protected.py` 生成，不要手改条目。名录若有新公告，换官方 PDF / 转载页后再跑脚本。
