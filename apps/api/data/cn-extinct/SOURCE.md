# IUCN 轴（查表，不问模型）

和中国重点保护 / 三有一样，这是评分的一条名录轴，不向模型提问。

中国没有「已灭绝物种」公告。此表收录 IUCN 红名单里、产品按 **XR** 处理的档：

- `EX` 灭绝
- `EW` 野外灭绝（只剩人工养殖）
- `CR` / `FE` 极危或功能灭绝（野外基本拍不到）

每条带评估页。命中即 XR，不再走后面的加减。

`EN`（濒危）、`VU`（易危）还没收进表，暂不参与计分。整张红名单含无危（LC），那些不是 XR。

产品例外（功能灭绝，按 XR）：

- **白鱀豚 / 白鳍豚** `Lipotes vexillifer`：IUCN 仍为 CR（Possibly Extinct），不是 EX。野外已多年无确认活体，旅行抽卡按拍不到处理。

仍不列入：

- 华南虎、中华鲟等：CR，且仍有确认活体或人工种群

名录若有新的 IUCN EX/EW 评估，补一行并写上 URL，不要靠记忆加种。
