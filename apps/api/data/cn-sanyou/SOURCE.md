# 三有名录（本地表）

法律依据：国家林业和草原局公告 **2023 年第 17 号**，2023-06-26 施行。

官方文本是扫描 PDF，中国政府网附件无内嵌文字，**没有开放「学名→三有」接口**。

| 文件 | 角色 | 是否入库 |
|---|---|---|
| `govcn-2023.pdf` | 中国政府网公告附件原件（扫描） | 否，见下方地址 |
| `zs-reprint.pdf` | 中山市林业局转载的同名录（可抽字） | 否，见下方地址 |
| `list.json` | 从该转载 PDF 解析出的结构化表 | **是**（评分依据） |

原始件体积大且是公开文件，不入 git（见 `.gitignore`）。要重跑解析先下回本目录：

- 政府网附件（扫描，无内嵌文字）：<https://www.gov.cn/zhengce/zhengceku/202307/P020230701333096616886.pdf> → 存为 `govcn-2023.pdf`
- 公告正文页：<https://www.gov.cn/zhengce/zhengceku/202307/content_6889361.htm>
- 可抽字的转载件：<https://www.zs.gov.cn/zslyj/attachment/0/471/471942/2298649.pdf> → 存为 `zs-reprint.pdf`

公告种数：1924 = 兽类 91 + 鸟类 1028 + 爬行 450 + 两栖 253 + 昆虫 96 + 蛛形 2 + 寡毛 4。  
解析结果必须与此加总一致。野猪已调出，表中不应出现 `Sus scrofa`。果子狸在册，备注「仅限野外种群」。

`list.json` 由 `apps/api/scripts/parse-cn-sanyou.py` 生成，不要手改条目。重跑需本机 `pypdf`。名录若有新公告，换官方 PDF / 转载件后再跑脚本。
